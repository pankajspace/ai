MCP & Evals Lab

Give an AI new abilities with MCP, then check it isn’t lying with evals — using a cricket-score assistant (all scores are made-up demo data)

🔌 MCP Plumbing

No AI at all — just MCP. The client starts the cricket MCP server, does the handshake (initialize), reads its menu cards (tools/list), and calls one tool by hand (tools/call). Try a player with get_player_stats, or Virat Kohli to see the error path.

🏏 Cricket Agent

Now the AI decides. The model reads the MCP menu cards, writes a “prescription” (which tool, which arguments), our code calls the tool, and the model answers from the result. Pick Both to see the same question answered with and without tools.

🧪 Eval Suite

Tests for an AI app: a list of questions, two code checks, and a score. Each case checks that the agent picked the expected tool (or no tool for “2 + 2”) and that the answer contains the key fact. Score the agent without tools to watch the evals catch it.
