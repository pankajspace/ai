🛵 QuickBite ETA

ML model (sklearn + FastAPI) in a single container. Covers Dockerfile anatomy, layer caching, port mapping, and .dockerignore. No API keys needed.

Level 1 · 1 container

📁 Files

Dockerfile · app.py · train.py · requirements.txt

🚀 Run it

cd src/quick-bite-eta
docker build -t quickbite-eta:v1 .
docker run -d -p 8000:8000 --name eta-service quickbite-eta:v1

# Test it
curl -X POST http://localhost:8000/predict \
  -H "Content-Type: application/json" \
  -d '{"distance_km": 4.5, "prep_time_min": 15, "rider_available": 1, "is_raining": 1}'

# Swagger UI: http://localhost:8000/docs

🔑 Concepts

FROM · WORKDIR · COPY · RUN · CMD · EXPOSE · layer caching trick · port mapping · .dockerignore · the photograph rule

🧹 Clean up

docker stop eta-service && docker rm eta-service

📚 ScalerGPT

RAG chatbot (FastAPI + OpenAI + ChromaDB) as a two-container Compose app. Adds secrets, volumes, service networking, and the "started ≠ ready" lesson.

Level 2 · 2 containers

📁 Files

Dockerfile · docker-compose.yml · app.py · ingest.py · docs/

🚀 Run it

cd src/scaler-gpt
cp .env.example .env          # add your OPENAI_API_KEY
docker compose up -d --build

# Wait for both containers, then ingest docs
docker compose exec app python ingest.py

# Ask a question
curl -X POST http://localhost:8000/ask \
  -H "Content-Type: application/json" \
  -d '{"query": "What is Docker?"}'

# Swagger UI: http://localhost:8000/docs

🔑 Concepts

secrets via .env · docker compose · service-name networking · volumes · published vs internal ports · started ≠ ready · retry loops · docker compose exec

🧹 Clean up

docker compose down        # keep data
docker compose down -v     # wipe vector DB

🤖 DeskBuddy

Agentic AI system with three containers (agent + tools + Redis). Adds microservice separation, private networking, the agent loop, and stateful memory.

Level 3 · 3 containers

📁 Files

docker-compose.yml · agent/ (Dockerfile + app.py) · tools/ (Dockerfile + app.py)

🚀 Run it

cd src/desk-buddy
cp .env.example .env          # add your OPENAI_API_KEY
docker compose up -d --build

# Two-tool task: calculator + clock
curl -X POST http://localhost:9000/chat \
  -H "Content-Type: application/json" \
  -d '{"session_id": "demo", "message": "What is 23*47, and what time is it?"}'

# Memory test: follow-up with same session_id
curl -X POST http://localhost:9000/chat \
  -H "Content-Type: application/json" \
  -d '{"session_id": "demo", "message": "Now double that multiplication result"}'

🔑 Concepts

microservice separation · private ports (no ports: = no public entrance) · the agent loop (think → act → observe) · Redis memory · lazy vs eager connections

🧹 Clean up

docker compose down        # keep memory
docker compose down -v     # wipe Redis
