How It Works#

The idea behind the demo, the request it sends and the function calls that answer it.

1

Concept#

Hello World Strands Agent is the entry point to the AWS Strands Agents SDK series. It demonstrates the minimal code needed to instantiate an autonomous agent backed by Amazon Bedrock (defaulting to amazon.nova-lite-v1:0 via BEDROCK_MODEL_ID) and run a natural-language prompt through its agentic loop.

With no tools attached, agent(prompt) executes a single model turn and returns an AgentResult object. Crucially, the service creates a fresh Agent(model=...) instance inside the request handler rather than at module import time, ensuring that concurrent web users never share or leak conversation state.

2

Theory#

1. Model vs. Agent in AWS Strands

A raw model client (like boto3.client("bedrock-runtime")) performs a single stateless text generation call. A Strands Agent wraps a BedrockModel with three higher-level capabilities that every subsequent demo in this module builds upon:

  • Conversation State (agent.messages): Automatically tracks user, assistant, tool-use, and tool-result blocks across turns.
  • Tool Registry (tools=[...]): Inspects decorated Python functions and exposes their schemas to Bedrock's Converse API.
  • Autonomous Execution Loop: Repeatedly cycles through model inference and local tool execution until the model produces a final answer.

2. Amazon Bedrock Converse API Integration

BedrockModel(model_id=model_id) authenticates using the standard AWS credential chain (AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, AWS_DEFAULT_REGION from .env, or an EC2/ECS IAM role) and communicates through Bedrock's unified Converse API, allowing you to swap between Amazon Nova Lite, Nova Pro, or Anthropic Claude models by changing only BEDROCK_MODEL_ID.

3. Request-Scoped Agent Instantiation (Multi-Tenant Safety)

Because a Strands Agent appends every prompt and reply to its internal agent.messages list, a global module-level Agent in a web server would mix User A's questions into User B's context. Instantiating Agent(...) per request guarantees clean isolation.

Code explanation#

1. Purpose of Each File in This Demo

  • src/python/01_hello_world_agent.py: Defines the minimal AWS Strands agent service. It loads environment variables, declares Pydantic request/response schemas, configures an Amazon Bedrock foundation model (BedrockModel), and exposes run_hello_world_agent(prompt) to execute a single-turn natural-language prompt.
  • src/python/app.py: The Flask web server and API gateway. Because Python module names cannot begin with digits in standard import statements, app.py dynamically loads 01_hello_world_agent.py via _load_service("01_hello_world_agent.py", "s_hello"), enforces IP-based rate limiting on POST requests, and exposes POST /api/hello-world-agent.
  • src/index.html + src/js/main.js: The interactive browser card that collects the user's prompt string, sends POST /api/hello-world-agent with JSON body { "prompt": "..." }, and renders the returned agent response.

2. Classes, Model Configuration, and Functions in 01_hello_world_agent.py

  • Step ① Environment Loading (load_dotenv(find_dotenv())): Walks up the directory tree to locate .env and injects AWS credentials (AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, AWS_DEFAULT_REGION) and optional model overrides into os.environ.
  • HelloWorldAgentRequest(BaseModel): Pydantic input schema holding a single field, prompt: str, defaulting to "Hello! Tell me a fun fact about AI agents.". It documents the expected input contract.
  • HelloWorldAgentResponse(BaseModel): Pydantic output schema specifying the two keys returned by the service: prompt: str (the echoed input) and response: str (the assistant's generated text).
  • Step ② Foundation Model Setup (model_id & model): Resolves the Bedrock model ID by checking BEDROCK_NOVA_LITE first, then BEDROCK_MODEL_ID, and finally defaulting to "amazon.nova-lite-v1:0". It wraps that identifier in BedrockModel(model_id=model_id), which is stateless and safe to reuse across requests.
  • run_hello_world_agent(prompt: str) -> dict: The main service entry point. Accepts the user's prompt string and performs two numbered steps:
    • Step ③ (agent = Agent(model=model)): Instantiates a fresh Strands Agent bound to the shared BedrockModel. Creating the Agent inside the function ensures each HTTP request starts with an empty agent.messages history.
    • Step ④ (response = agent(prompt)): Invokes the agent's __call__ method, which formats the prompt as a Bedrock Converse user message, sends it to Amazon Nova Lite, and returns an AgentResult object. Converting it with str(response) extracts the plain text reply, returning {"prompt": prompt, "response": str(response)}.

3. Server Loader, Middleware, and Route Handler in app.py

  • _load_service(filename: str, alias: str): Uses importlib.util.spec_from_file_location (Step ①) and spec.loader.exec_module(mod) (Step ②) to load numbered Python files like 01_hello_world_agent.py into sys.modules["services.s_hello"] and assign the module object to s_hello.
  • enforce_rate_limit() (@bp.before_request): Intercepts every incoming POST request (Step ①), calls check_rate_limit(request, max_requests=30, window_seconds=3600) (Step ②), and returns HTTP 429 Too Many Requests with a Retry-After header if the client exceeds 30 calls per hour (Step ③).
  • hello_world_route() (POST /api/hello-world-agent):
    • Step ①: Parses the incoming JSON body via request.get_json(force=True, silent=True), extracts prompt (or fallback key message), strips whitespace, and returns HTTP 400 if empty.
    • Step ②: Calls s_hello.run_hello_world_agent(prompt), copies res["response"] into res["result"] for frontend compatibility, and serializes the dictionary as JSON via jsonify(res) (catching any AWS/runtime exceptions as HTTP 500).

4. End-to-End Execution Walkthrough

  1. The user clicks Run on the Hello World card in src/index.html; src/js/main.js sends POST /api/hello-world-agent with { "prompt": "Hello! Tell me a fun fact about AI agents." }.
  2. Flask's Blueprint before_request hook (enforce_rate_limit) verifies the client is within the 30 requests/hour quota.
  3. hello_world_route() in app.py validates the non-empty prompt and calls s_hello.run_hello_world_agent(prompt).
  4. Inside 01_hello_world_agent.py, run_hello_world_agent() creates a request-scoped Agent(model=model) and calls agent(prompt).
  5. Strands sends a Converse API request via boto3 to Amazon Bedrock (amazon.nova-lite-v1:0). Because no tools are registered, the model answers in a single turn.
  6. run_hello_world_agent() casts the AgentResult to str(response) and returns {"prompt": prompt, "response": "..."} to app.py, which adds "result" and returns the JSON payload to the browser.

AWS Strands Hello World Agent Service.

"""AWS Strands Hello World Agent Service.

Demonstrates the simplest possible autonomous agent:
1. Configures a foundation model (Amazon Nova Lite on Bedrock).
2. Wraps the model in a Strands Agent instance (the agentic loop).
3. Executes a natural language prompt and returns the reply.
"""

import os

from dotenv import find_dotenv, load_dotenv
from pydantic import BaseModel
from strands import Agent
from strands.models.bedrock import BedrockModel

# ① Load AWS credentials and Bedrock configuration from .env
load_dotenv(find_dotenv())


class HelloWorldAgentRequest(BaseModel):
    """Input payload for Hello World Agent."""

    prompt: str = "Hello! Tell me a fun fact about AI agents."


class HelloWorldAgentResponse(BaseModel):
    """Output payload from Hello World Agent."""

    prompt: str
    response: str


# ② Configure the Bedrock foundation model (Amazon Nova Lite is fast and cost-effective)
model_id = os.getenv("BEDROCK_NOVA_LITE", os.getenv("BEDROCK_MODEL_ID", "amazon.nova-lite-v1:0"))
model = BedrockModel(model_id=model_id)


def run_hello_world_agent(prompt: str = "Hello! Tell me a fun fact about AI agents.") -> dict:
    """Execute the Hello World Agent on Amazon Bedrock via Strands."""
    # ③ Wrap the foundation model in a Strands Agent instance
    agent = Agent(model=model)

    # ④ Execute the natural language prompt through the agentic loop
    response = agent(prompt)

    return {"prompt": prompt, "response": str(response)}

def _load_service(filename: str, alias: str):
    # ① Resolve the numbered service file path and create its import spec
    file_path = _CUR_DIR / filename
    spec = importlib.util.spec_from_file_location(f"services.{alias}", file_path)
    if spec is None or spec.loader is None:
        raise ImportError(f"Cannot load module from {file_path}")
    # ② Register and execute the module so its functions can be called by routes
    mod = importlib.util.module_from_spec(spec)
    sys.modules[f"services.{alias}"] = mod
    spec.loader.exec_module(mod)
    return mod

@bp.before_request
def enforce_rate_limit():
    # ① Only rate-limit mutating POST requests
    if request.method == "POST":
        # ② Check whether this client has exceeded 30 requests per hour
        blocked, msg, retry_after = check_rate_limit(
            request, max_requests=30, window_seconds=3600
        )
        if blocked:
            # ③ Return HTTP 429 with Retry-After header when rate-limited
            resp = jsonify({"error": msg})
            resp.status_code = 429
            resp.headers["Retry-After"] = str(retry_after)
            return resp

@bp.route("/api/hello-world-agent", methods=["POST"])
def hello_world_route():
    # ① Parse prompt from JSON payload and reject empty values
    data = request.get_json(force=True, silent=True) or {}
    prompt = (data.get("prompt") or data.get("message") or "").strip()
    if not prompt:
        return jsonify({"error": "Prompt cannot be empty"}), 400
    try:
        # ② Invoke the Strands Hello World Agent in 01_hello_world_agent.py
        res = s_hello.run_hello_world_agent(prompt)
        res["result"] = res.get("response") or res.get("answer") or ""
        return jsonify(res)
    except Exception as exc:
        return jsonify({"error": str(exc)}), 500

Quick revision#

Use these core takeaways to review how AWS Strands initializes and runs a foundational Bedrock agent:

  1. Two-Object Architecture (BedrockModel + Agent): In AWS Strands, BedrockModel encapsulates the stateless foundation model connection and inference parameters, while Agent provides the stateful conversation history (agent.messages), tool registry, and autonomous execution loop.
  2. Default Foundation Model (amazon.nova-lite-v1:0): The service resolves BEDROCK_NOVA_LITE or BEDROCK_MODEL_ID from .env and defaults to Amazon Nova Lite — a low-latency, cost-efficient multimodal model ideal for interactive agent loops.
  3. Unified Bedrock Converse API: Under the hood, BedrockModel communicates through Amazon Bedrock's Converse API, meaning you can switch between Amazon Nova, Anthropic Claude, or Meta Llama models by changing only the model ID string.
  4. Zero-Tool Single-Turn Execution: When Agent(model=model) is initialized without a tools=[...] list, calling agent(prompt) executes a single Converse turn and returns an AgentResult object that stringifies cleanly via str(response).
  5. Request-Scoped Agent Instantiation: Because a Strands Agent appends every user prompt and assistant response to agent.messages, run_hello_world_agent() creates a new Agent(model=model) on each request while reusing the stateless BedrockModel, preventing cross-user context leakage in a multi-tenant web server.
  6. Standard AWS Credential Chain: Calling load_dotenv(find_dotenv()) populates environment variables that boto3 automatically discovers alongside IAM roles or AWS CLI profiles.
  7. Dynamic Module Loading for Numbered Scripts: In app.py, _load_service() uses importlib.util.spec_from_file_location so learning scripts can keep their ordered filenames (01_hello_world_agent.py) while still being imported cleanly into Flask routes.
  8. Pydantic Contract Documentation: Defining HelloWorldAgentRequest and HelloWorldAgentResponse makes the expected JSON payload and response shape explicit and self-documenting.
