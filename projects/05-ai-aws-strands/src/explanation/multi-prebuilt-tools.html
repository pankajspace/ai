The idea behind the demo, the request it sends and the function calls that answer it.

1

Concept#

Multi-Prebuilt Tools Agent demonstrates how an agent can chain multiple off-the-shelf tools from strands_tools — specifically http_request and calculator — to execute an end-to-end live data analysis pipeline without writing a single line of custom tool code.

When prompted to fetch 5-day stock chart data from Yahoo Finance's JSON API, extract the closing prices, compute their average, and summarize the trend, the Bedrock agent autonomously calls http_request(method="GET", url=...) first, parses the nested JSON payload returned by the server, passes the extracted closing price array into calculator to compute the exact mean, and writes a clear summary report.

2

Theory#

1. Cross-Domain Tool Chaining (Network I/O → Computation)

Real-world data workflows rarely stop after a single tool call. Here, two prebuilt tools with completely different responsibilities cooperate through the agent's conversation context:

  1. Data Acquisition (http_request): Fetches live external JSON over HTTPS and places the response body into a toolResult block.
  2. LLM Parsing & Extraction: On the next reasoning turn, the LLM reads the raw JSON structure, locates the closing price array, and constructs a mathematical expression.
  3. Exact Computation (calculator): Computes the exact average so the final summary never suffers from LLM floating-point rounding errors.

2. Human-in-the-Loop Tool Consent for Mutating Operations

strands_tools enforces built-in safety boundaries: while http_request allows read-only GET requests automatically, it prompts for human confirmation on state-changing HTTP verbs (POST, PUT, PATCH, DELETE), and tools like file_write require interactive consent unless BYPASS_TOOL_CONSENT=true is set. In a headless web server with no interactive terminal, omitting file_write and sticking to read-only GET calls keeps the server safe from arbitrary file writes or external mutations.

3. Observability Through tool_sequence

By scanning agent.messages for "toolUse" blocks after the run, the service returns the ordered list of tool calls (http_request(...) followed by calculator(...)) so you can verify the exact execution trace.

Multi-Prebuilt Tools Agent Service.

"""Multi-Prebuilt Tools Agent Service.

Demonstrates chaining multiple prebuilt tools in one pipeline:
1. Prebuilt tools from `strands_tools`: `http_request` (fetch) and `calculator` (math).
2. Handles multi-step pipelines: Fetch external API data -> Compute statistics -> Summarize.
3. The practice script also saves the summary with the prebuilt `file_write`; this web demo
   returns the summary to the UI instead, so nothing is written on the server.
"""

import os

from dotenv import find_dotenv, load_dotenv
from pydantic import BaseModel
from strands import Agent
from strands.models.bedrock import BedrockModel
from strands_tools import calculator, http_request

# ① Load AWS credentials and Bedrock configuration from .env
load_dotenv(find_dotenv())


class MultiPrebuiltToolsRequest(BaseModel):
    """Input payload for Multi Prebuilt Tools Agent."""

    task: str = (
        "Fetch stock data from https://query1.finance.yahoo.com/v8/finance/chart/AAPL?interval=1d&range=5d, "
        "extract the latest closing prices, calculate the average price over the period, "
        "and show a short summary"
    )


class MultiPrebuiltToolsResponse(BaseModel):
    """Output payload from Multi Prebuilt Tools Agent."""

    task: str
    response: str
    tool_sequence: list[str]


# ② Resolve the target Bedrock model identifier
model_id = os.getenv("BEDROCK_MODEL_ID", "amazon.nova-lite-v1:0")


def run_multi_prebuilt_tools_agent(task: str) -> dict:
    """Run the Multi Prebuilt Tools Agent."""
    # ③ Initialize the Strands Agent with the prebuilt http_request and calculator tools
    agent = Agent(
        model=BedrockModel(model_id=model_id),
        tools=[http_request, calculator],
        system_prompt="You help with data analysis tasks.",
    )

    # ④ Execute the multi-step pipeline: fetch HTTP data -> compute average -> summarize
    response = agent(task)

    # ⑤ Collect the tool calls in the order the agent made them
    tool_calls = [
        f"{block['toolUse']['name']}({block['toolUse']['input']})"
        for message in agent.messages
        for block in message["content"]
        if "toolUse" in block
    ]

    return {"task": task, "response": str(response), "tool_sequence": tool_calls}

def _load_service(filename: str, alias: str):
    # ① Resolve the numbered service file path and create its import spec
    file_path = _CUR_DIR / filename
    spec = importlib.util.spec_from_file_location(f"services.{alias}", file_path)
    if spec is None or spec.loader is None:
        raise ImportError(f"Cannot load module from {file_path}")
    # ② Register and execute the module so its functions can be called by routes
    mod = importlib.util.module_from_spec(spec)
    sys.modules[f"services.{alias}"] = mod
    spec.loader.exec_module(mod)
    return mod

@bp.before_request
def enforce_rate_limit():
    # ① Only rate-limit mutating POST requests
    if request.method == "POST":
        # ② Check whether this client has exceeded 30 requests per hour
        blocked, msg, retry_after = check_rate_limit(
            request, max_requests=30, window_seconds=3600
        )
        if blocked:
            # ③ Return HTTP 429 with Retry-After header when rate-limited
            resp = jsonify({"error": msg})
            resp.status_code = 429
            resp.headers["Retry-After"] = str(retry_after)
            return resp

@bp.route("/api/hello-world-agent", methods=["POST"])
def hello_world_route():
    # ① Parse prompt from JSON payload and reject empty values
    data = request.get_json(force=True, silent=True) or {}
    prompt = (data.get("prompt") or data.get("message") or "").strip()
    if not prompt:
        return jsonify({"error": "Prompt cannot be empty"}), 400
    try:
        # ② Invoke the Strands Hello World Agent in 01_hello_world_agent.py
        res = s_hello.run_hello_world_agent(prompt)
        res["result"] = res.get("response") or res.get("answer") or ""
        return jsonify(res)
    except Exception as exc:
        return jsonify({"error": str(exc)}), 500
