Minimal single-turn Amazon Nova Lite agent invocation via the AWS Strands Agents SDK.

LangGraph create_react_agent with ChatBedrockConverse (Nova Lite) and a @tool greet(name) function.

Multi-parameter @tool calculate_tip(bill_amount: float, tip_percentage: float = 15.0, num_people: int = 1).

Extracts typed numeric arguments and defaults from natural language to compute tip, total bill, and per-person split.

Sequential 3-tool chain: get_sales_data(quarter) → analyze_sales(revenue, deals, quarter) → send_email(to, subject, body).
