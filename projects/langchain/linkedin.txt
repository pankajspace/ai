🚀 Day 2 — I went from calling an LLM to building chains, memory, and agents with LangChain.

Yesterday I shipped a raw-API playground. Today I rebuilt it the LangChain way — and added capabilities that weren't possible before. ✨

What the new LangChain Lab does:
🔎 Website Summarizer — paste any URL and a LangChain prompt | model | parser chain returns a clean summary
🧠 Memory Chat — a chatbot that actually remembers the conversation by re-sending history every turn
🛍️ Shop Agent — a tool-using agent that decides on its own when to call a price-lookup tool and phrases a natural-language answer

The 3 big concepts I learned:
⛓️ Chains — composing prompt → model → parser in one line
💬 Memory — an LLM has zero memory; you fake it by re-sending prior turns
🤖 Agents — give the model a tool and a loop, and it figures out when to use it
