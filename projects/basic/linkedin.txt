🚀 I just built & shipped my very first AI app — on Day 1.

It's an AI Playground with 4 mini-tools that put two different LLMs to work — OpenAI's GPT-4o mini and Groq's Llama 3.3 70B — all behind one clean web UI. ✨

The 4 things it does:
😂 Joke Generator — cracks a fresh joke on any topic (Llama 3.3 70B)
✈️ Travel Suggestion — tells you one cool thing to do in any city (GPT-4o mini)
🔎 Website Summarizer — paste a URL, get a clean summary in seconds
🥊 LLM Arena — ask both models the same question and watch them go head-to-head

The mind-blowing part? It's basically just:
🧠 send a prompt to an LLM
🔌 swap providers using the same OpenAI-compatible client
🐳 wrap it all in a Flask app running in Docker
