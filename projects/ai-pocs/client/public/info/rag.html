Concept#

📚 Paragraph RAG runs a complete 4-stage Retrieval-Augmented Generation pipeline in memory: splitting a paragraph into sentences, embedding them with all-MiniLM-L6-v2, ranking every sentence against the question by cosine similarity, and passing the top-k sentences to OpenAI to generate a grounded answer.

Instead of asking the LLM to answer from parametric memory (which risks hallucination) or stuffing an entire document into the prompt, RAG retrieves only the highest-scoring evidence chunks and instructs the model to answer exclusively from that retrieved context.

2

Theory & Concepts#

Core Concepts:

  • 4-Stage RAG Pipeline: Chunking (sentence boundary regex) → Embedding (SentenceTransformer) → Vector Retrieval (cosine similarity top-$k$) → Grounded Generation (gpt-4o-mini).
  • Grounding Constraint: The prompt explicitly instructs: "Answer the question using ONLY the context below."
  • Retrieval Transparency: Returning all ranked sentences with their cosine scores lets users inspect why specific chunks were selected.
3

Request flow#

🧑 Browser RagCard.tsx sends POST /api/rag with paragraph and question.
→
FastAPI Route (server/main.py) rag_service(req) validates the inputs and invokes answer_rag(paragraph, question).
→
Chunk & Embed (10_rag.py) split_sentences() splits the paragraph; all-MiniLM-L6-v2 encodes all sentences and the query into 384-D vectors.
→
Rank & Retrieve Computes cosine similarity for each sentence, sorts descending, and selects the top-3 sentences as context.
→
Grounded Generation Sends the top-3 sentences and question to OpenAI gpt-4o-mini to synthesize the final answer.
→
🧑 Browser Returns RagResponse with the grounded answer, top_context, and full ranked_chunks list.

server/services/10_rag.py

Paragraph RAG (Retrieval-Augmented Generation) Service.

"""Paragraph RAG (Retrieval-Augmented Generation) Service.

This service implements a RAG workflow for answering questions over a paragraph:
1. Splits the paragraph into manageable text chunks using RecursiveCharacterTextSplitter.
2. Indexes chunks and retrieves the top matching passages for the user question.
3. Formulates a grounded prompt with the retrieved context.
4. Generates a concise, fact-based answer using ChatOpenAI.

Run directly:
    python projects/ai-pocs/server/services/10_rag.py
"""

import os
from dotenv import find_dotenv, load_dotenv
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from pydantic import BaseModel, Field

from langchain_text_splitters import RecursiveCharacterTextSplitter

load_dotenv(find_dotenv())

DEFAULT_SAMPLE_PARAGRAPH = (
    "TechToday Return Policy: Customers may return any eligible product within 30 days "
    "of the purchase date. All returned merchandise must be unworn, undamaged, and in its "
    "original packaging with all tags attached. Refunds are processed back to the original "
    "payment method within 5 to 7 business days after inspection. Standard shipping fees "
    "are non-refundable unless the return is due to our fulfillment error. International "
    "orders and clearance items marked as final sale cannot be returned or exchanged."
)

DEFAULT_SAMPLE_QUESTION = "How long do I have to return something?"

# RAG prompt: instructs the model to answer strictly from retrieved context
RAG_PROMPT = ChatPromptTemplate.from_template("""
Answer the question using ONLY the context below. If the context doesn't contain
the answer, say "I couldn't find that in the provided paragraph."
Be concise and quote facts directly.

Context:
{context}

Question: {question}
""")


# ---------------------------------------------------------------------------
# Request & Response Schemas (Pydantic)
# ---------------------------------------------------------------------------
class RagRequest(BaseModel):
    """Input payload for paragraph-based RAG query."""

    paragraph: str = Field(
        default=DEFAULT_SAMPLE_PARAGRAPH,
        description="Paragraph or document text to query",
    )
    question: str = Field(
        default=DEFAULT_SAMPLE_QUESTION,
        description="Question to ask about the paragraph",
    )


class RagResponse(BaseModel):
    """Output payload containing grounded answer and retrieved sources."""

    paragraph: str
    question: str
    answer: str
    sources: list[str]


# ---------------------------------------------------------------------------
# Retrieval & RAG Logic
# ---------------------------------------------------------------------------
def _retrieve_relevant_chunks(chunks: list[str], question: str, k: int = 3) -> list[str]:
    """Retrieve top relevant chunks using Chroma vector store and HuggingFace embeddings."""
    # ① Short-circuit if total chunks are already within the top-k limit
    if len(chunks) <= k:
        return chunks

    from langchain_chroma import Chroma
    from langchain_huggingface import HuggingFaceEmbeddings

    # ② Embed all chunks into an ephemeral Chroma vector store
    embedder = HuggingFaceEmbeddings(model_name="all-MiniLM-L6-v2")
    db = Chroma.from_texts(chunks, embedder)
    # ③ Run similarity search for the user question and return top-k passages
    results = db.similarity_search(question, k=k)
    return [r.page_content for r in results]


def answer_rag(
    paragraph: str = DEFAULT_SAMPLE_PARAGRAPH,
    question: str = DEFAULT_SAMPLE_QUESTION,
) -> dict:
    """Execute the complete paragraph RAG pipeline: chunk -> retrieve -> synthesize.

    Args:
        paragraph: The source paragraph to search.
        question: User query about the paragraph.

    Returns:
        Dictionary matching RagResponse schema.
    """
    # ① Chunk the paragraph into overlapping pieces
    splitter = RecursiveCharacterTextSplitter(chunk_size=200, chunk_overlap=40)
    chunks = splitter.split_text(paragraph)
    if not chunks:
        chunks = [paragraph]

    # ② Retrieve the most relevant chunks for the question
    relevant_chunks = _retrieve_relevant_chunks(chunks, question, k=3)

    # ③ Format the retrieved chunks into context string
    context = "\n\n".join(relevant_chunks)

    # ④ Initialize chat model
    model = ChatOpenAI(
        model=os.getenv("OPENAI_MODEL", "gpt-4o-mini"),
        api_key=os.getenv("OPENAI_API_KEY"),
        base_url=os.getenv("OPENAI_BASE_URL") or None,
        temperature=0,
    )

    # ⑤ Synthesize answer with prompt chain
    chain = RAG_PROMPT | model
    result = chain.invoke({"context": context, "question": question})
    answer = result.content if hasattr(result, "content") else str(result)

    return {
        "paragraph": paragraph,
        "question": question,
        "answer": str(answer).strip(),
        "sources": relevant_chunks,
    }


# ---------------------------------------------------------------------------
# Standalone CLI Verification
# ---------------------------------------------------------------------------
if __name__ == "__main__":
    print("--- Paragraph RAG Service ---")
    res = answer_rag(DEFAULT_SAMPLE_PARAGRAPH, DEFAULT_SAMPLE_QUESTION)
    print(f"\nQuestion: {res['question']}")
    print(f"\nRetrieved Chunks ({len(res['sources'])}):")
    for i, s in enumerate(res['sources'], 1):
        print(f" [{i}] {s}")
    print(f"\nAnswer:\n{res['answer']}")

server/main.py

FastAPI route handler for POST /api/rag (rag_service) in server/main.py.

from dotenv import find_dotenv, load_dotenv
from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware

from services import (
    RagRequest,
    RagResponse,
    answer_rag,
)

# Load environment variables
load_dotenv(find_dotenv())

app = FastAPI(title="AI POCs API")

# Enable CORS for frontend requests
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.post("/api/rag", response_model=RagResponse)
def rag_service(req: RagRequest):
    # ① Validate paragraph and question before running the 4-stage RAG pipeline
    paragraph = req.paragraph.strip() if req.paragraph else ""
    question = req.question.strip() if req.question else ""
    if not paragraph:
        raise HTTPException(status_code=400, detail="Paragraph cannot be empty")
    if not question:
        raise HTTPException(status_code=400, detail="Question cannot be empty")
    try:
        res = answer_rag(paragraph=paragraph, question=question)
        return RagResponse(**res)
    except Exception as exc:
        raise HTTPException(status_code=500, detail=str(exc))
