🌐 Hello World Agent#

How It Works#

The idea behind the demo, the request it sends and the function calls that answer it.

1

Concept#

Hello World Strands Agent is the entry point to the AWS Strands Agents SDK series. It demonstrates the minimal code needed to instantiate an autonomous agent backed by Amazon Bedrock (defaulting to amazon.nova-lite-v1:0 via BEDROCK_MODEL_ID) and run a natural-language prompt through its agentic loop.

With no tools attached, agent(prompt) executes a single model turn and returns an AgentResult object. Crucially, the service creates a fresh Agent(model=...) instance inside the request handler rather than at module import time, ensuring that concurrent web users never share or leak conversation state.

2

Theory#

1. Model vs. Agent in AWS Strands

A raw model client (like boto3.client("bedrock-runtime")) performs a single stateless text generation call. A Strands Agent wraps a BedrockModel with three higher-level capabilities that every subsequent demo in this module builds upon:

  • Conversation State (agent.messages): Automatically tracks user, assistant, tool-use, and tool-result blocks across turns.
  • Tool Registry (tools=[...]): Inspects decorated Python functions and exposes their schemas to Bedrock's Converse API.
  • Autonomous Execution Loop: Repeatedly cycles through model inference and local tool execution until the model produces a final answer.

2. Amazon Bedrock Converse API Integration

BedrockModel(model_id=model_id) authenticates using the standard AWS credential chain (AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, AWS_DEFAULT_REGION from .env, or an EC2/ECS IAM role) and communicates through Bedrock's unified Converse API, allowing you to swap between Amazon Nova Lite, Nova Pro, or Anthropic Claude models by changing only BEDROCK_MODEL_ID.

3. Request-Scoped Agent Instantiation (Multi-Tenant Safety)

Because a Strands Agent appends every prompt and reply to its internal agent.messages list, a global module-level Agent in a web server would mix User A's questions into User B's context. Instantiating Agent(...) per request guarantees clean isolation.

01_hello_world_agent.py#

AWS Strands Hello World Agent Service.

"""AWS Strands Hello World Agent Service.

Demonstrates the simplest possible autonomous agent:
1. Configures a foundation model (Amazon Nova Lite on Bedrock).
2. Wraps the model in a Strands Agent instance (the agentic loop).
3. Executes a natural language prompt and returns the reply.
"""

import os

from dotenv import find_dotenv, load_dotenv
from pydantic import BaseModel
from strands import Agent
from strands.models.bedrock import BedrockModel

# ① Load AWS credentials and Bedrock configuration from .env
load_dotenv(find_dotenv())


class HelloWorldAgentRequest(BaseModel):
    """Input payload for Hello World Agent."""

    prompt: str = "Hello! Tell me a fun fact about AI agents."


class HelloWorldAgentResponse(BaseModel):
    """Output payload from Hello World Agent."""

    prompt: str
    response: str


# ② Configure the Bedrock foundation model (Amazon Nova Lite is fast and cost-effective)
model_id = os.getenv("BEDROCK_NOVA_LITE", os.getenv("BEDROCK_MODEL_ID", "amazon.nova-lite-v1:0"))
model = BedrockModel(model_id=model_id)


def run_hello_world_agent(prompt: str = "Hello! Tell me a fun fact about AI agents.") -> dict:
    """Execute the Hello World Agent on Amazon Bedrock via Strands."""
    # ③ Wrap the foundation model in a Strands Agent instance
    agent = Agent(model=model)

    # ④ Execute the natural language prompt through the agentic loop
    response = agent(prompt)

    return {"prompt": prompt, "response": str(response)}

main.py#

34 lines

FastAPI route handler for POST /api/hello-world-agent (hello_world_agent_service) in server/main.py.

from dotenv import find_dotenv, load_dotenv
from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware

from services import (
    HelloWorldAgentRequest,
    HelloWorldAgentResponse,
    run_hello_world_agent,
)

# Load environment variables
load_dotenv(find_dotenv())

app = FastAPI(title="AI POCs API")

# Enable CORS for frontend requests
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.post("/api/hello-world-agent", response_model=HelloWorldAgentResponse)
def hello_world_agent_service(req: HelloWorldAgentRequest):
    # ① Validate prompt and invoke AWS Strands Hello World Agent
    if not req.prompt.strip():
        raise HTTPException(status_code=400, detail="Prompt cannot be empty")
    try:
        return HelloWorldAgentResponse(**run_hello_world_agent(req.prompt))
    except Exception as exc:
        raise HTTPException(status_code=500, detail=str(exc))
