Concept#

LangGraph ReAct Agent sits right beside the Strands Hello World demo to prove a key architectural insight: the ReAct (Reason + Act) agent pattern is universal across AI frameworks. Here, the same Amazon Bedrock model (amazon.nova-lite-v1:0) is driven by LangGraph's create_react_agent() instead of AWS Strands.

Equipped with a simple @tool def greet(name: str) -> str tool, the agent is asked to "Greet Alice and Bob". It reasons that two greetings are needed, invokes greet("Alice") and greet("Bob"), observes the friendly outputs, and synthesizes a final response while the service extracts all intermediate tool messages from the graph state for display in the UI.

2

Theory & Concepts#

1. The ReAct Loop (Reason → Act → Observe)

Whether implemented in LangGraph, AWS Strands, or raw OpenAI code, a ReAct agent executes the same cyclic state graph:

  1. Reason (Agent Node): The LLM inspects the conversation state and decides whether it needs external tool actions or can answer immediately.
  2. Act (Tools Node): If the LLM emits tool_calls, the graph routes to the tool executor node, which runs greet(name) for each call.
  3. Observe (State Edge): Each tool output is appended to the state's messages list as a ToolMessage, and control loops back to the Agent Node.

2. Side-by-Side Framework Comparison: Strands vs. LangGraph

  • Model Setup: Strands uses BedrockModel(model_id=...); LangChain/LangGraph uses init_chat_model(model_id, model_provider="bedrock_converse").
  • Tool Decorator: Strands uses from strands import tool; LangGraph uses from langchain_core.tools import tool.
  • Invocation: Strands calls agent(prompt); LangGraph calls agent.invoke({"messages": [("user", prompt)]}).

3. Extracting Tool Outputs from Graph State

LangGraph returns the complete state dictionary {"messages": [...]}. Filtering for getattr(m, "type", None) == "tool" isolates the exact strings returned by greet(), while messages[-1].content holds the assistant's final reply.

LangGraph ReAct Hello World Agent Service.

"""LangGraph ReAct Hello World Agent Service.

Demonstrates the LangGraph tool-calling ReAct agentic loop on Amazon Bedrock:
1. Defines a tool `greet(name: str)`.
2. Passes the prompt to a LangGraph ReAct agent backed by Bedrock Converse.
3. Observes tool execution steps (calling greet for each person).
4. Synthesizes the final response.
"""

import os

from dotenv import find_dotenv, load_dotenv
from langchain.chat_models import init_chat_model
from langchain.tools import tool
from langgraph.prebuilt import create_react_agent
from pydantic import BaseModel

# ① Load AWS credentials and Bedrock configuration from .env
load_dotenv(find_dotenv())


class LangGraphAgentRequest(BaseModel):
    """Input payload for LangGraph Hello World Agent."""

    prompt: str = "Please greet Alice and Bob."


class LangGraphAgentResponse(BaseModel):
    """Output payload from LangGraph Hello World Agent."""

    prompt: str
    response: str
    tool_calls: list[str]


# ② Resolve the target Bedrock model identifier
model_id = os.getenv("BEDROCK_MODEL_ID", "amazon.nova-lite-v1:0")


@tool
def greet(name: str) -> str:
    """Greet someone by name."""
    return f"Hello, {name}! Welcome to the world of AI agents."


# ③ Initialize the LLM via the Amazon Bedrock Converse provider
llm = init_chat_model(model_id, model_provider="bedrock_converse")

# ④ Create a LangGraph ReAct agent bound to the greet tool
agent = create_react_agent(model=llm, tools=[greet])


def run_langgraph_agent(prompt: str = "Please greet Alice and Bob.") -> dict:
    """Run the LangGraph tool-enabled ReAct agent."""
    # ⑤ Invoke the ReAct agent loop (Reason -> Act -> Observe)
    response = agent.invoke({"messages": [{"role": "user", "content": prompt}]})
    messages = response["messages"]

    # ⑥ Every "tool" message is the observation from one greet() call
    tool_calls = [f"{m.name} -> {m.content}" for m in messages if m.type == "tool"]

    return {"prompt": prompt, "response": messages[-1].text, "tool_calls": tool_calls}

server/main.py

FastAPI route handler for POST /api/langgraph-agent (langgraph_agent_service) in server/main.py.

from dotenv import find_dotenv, load_dotenv
from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware

from services import (
    LangGraphAgentRequest,
    LangGraphAgentResponse,
    run_langgraph_agent,
)

# Load environment variables
load_dotenv(find_dotenv())

app = FastAPI(title="AI POCs API")

# Enable CORS for frontend requests
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.post("/api/langgraph-agent", response_model=LangGraphAgentResponse)
def langgraph_agent_service(req: LangGraphAgentRequest):
    # ① Validate prompt and invoke LangGraph ReAct greeting agent
    if not req.prompt.strip():
        raise HTTPException(status_code=400, detail="Prompt cannot be empty")
    try:
        return LangGraphAgentResponse(**run_langgraph_agent(req.prompt))
    except Exception as exc:
        raise HTTPException(status_code=500, detail=str(exc))
