🛵 Delivery ETA Model Training#

🛵 Delivery ETA Model Training generates a synthetic food delivery dataset, trains a scikit-learn RandomForestRegressor, saves the model artifact with joblib, and predicts delivery ETA in minutes.

Unit 1

How It Works#

The idea behind the demo, the request it sends and the function calls that answer it.

1

Concept#

Before deploying an ML model behind a FastAPI microservice, the training job produces a serialized model artifact (eta_model.joblib). At inference time, the service loads that artifact once and predicts delivery ETA from four numeric features: distance, items count, peak hour indicator, and traffic level.

2

Theory & Concepts#

  • Train vs. Serve separation: Training runs once and writes eta_model.joblib; inference loads the saved artifact for fast predictions.
  • RandomForestRegressor: An ensemble of 120 decision trees that predicts a continuous target (ETA in minutes) and exposes feature importances.
  • Mean Absolute Error (MAE): Measures the average absolute difference in minutes between predicted and actual delivery times on the held-out 20% test split.
3

Request flow#

🧑 Browser ModelTrainingCard.tsx sends POST /api/model-training with order features.
→
FastAPI route (main.py) model_training_service(req) calls predict_delivery_eta().
→
Model Artifact (01_model_training.py) Loads or trains RandomForestRegressor via joblib and runs model.predict().
→
🧑 Browser Displays predicted ETA in minutes, test MAE, and feature importances.

from pathlib import Path
import random
import joblib
import pandas as pd
from pydantic import BaseModel, Field
from sklearn.ensemble import RandomForestRegressor
from sklearn.metrics import mean_absolute_error
from sklearn.model_selection import train_test_split

FEATURES = ["distance_km", "items_count", "is_peak_hour", "traffic_level"]

def predict_delivery_eta(
    distance_km: float,
    items_count: int,
    is_peak_hour: int,
    traffic_level: int,
) -> dict:
    model, mae, importances = _ensure_trained_model()
    sample = pd.DataFrame([{
        "distance_km": distance_km,
        "items_count": items_count,
        "is_peak_hour": is_peak_hour,
        "traffic_level": traffic_level,
    }])
    pred = float(model.predict(sample)[0])
    return {
        "distance_km": distance_km,
        "items_count": items_count,
        "is_peak_hour": is_peak_hour,
        "traffic_level": traffic_level,
        "predicted_eta_minutes": round(pred, 1),
        "test_mae_minutes": mae,
        "feature_importances": importances,
    }

@app.post("/api/model-training", response_model=ModelTrainingResponse)
def model_training_service(req: ModelTrainingRequest):
    try:
        return ModelTrainingResponse(
            **predict_delivery_eta(
                req.distance_km,
                req.items_count,
                req.is_peak_hour,
                req.traffic_level,
            )
        )
    except Exception as exc:
        raise HTTPException(status_code=500, detail=str(exc))
