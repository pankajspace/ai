🧠 Conversational Memory#

🧠 Conversational Memory gives a stateless LLM a memory by sending the whole chat history back with every new question, using LangChain's MessagesPlaceholder.

6 Topics • 4 Explainers • 2 Python Files in Full
Unit 1

How It Works#

The idea behind the demo, the request it sends and the function calls that answer it.

1

Concept#

LLMs do not remember earlier requests. To make a chat feel continuous, the browser keeps the list of past messages and sends it with each new message; the prompt template places that history between the system message and the new question.

After the model answers, the service returns the history with the new question and answer appended, ready for the next turn. "Clear Memory" simply empties that list.

2

Theory & Concepts#

  • Stateless models: each API call only sees what you send in that call.
  • MessagesPlaceholder: a slot in the prompt that is filled with a list of (role, content) messages.
  • Client-held state: the server stores nothing — the history travels in the request and response.
  • Cost of memory: longer history means more tokens on every call.
3

Request flow#

🧑 Browser MemoryChatCard.tsx sends POST /api/memory-chat with { message, history }.
→
FastAPI route (main.py) memory_chat_service(req) calls chat_with_memory(message, history).
→
Service (04_langchain_memory_chat.py) Turns the history into (role, content) tuples and invokes prompt | model.
→
OpenAI API Answers using the past messages as context.
→
🧑 Browser Receives { response, history } and keeps the updated history for the next turn.

server/services/04_langchain_memory_chat.py

LangChain Conversational Memory Chat Service.

"""LangChain Conversational Memory Chat Service.

This service demonstrates conversational memory using LangChain LCEL (LangChain Expression Language):
1. Loads API credentials and model configuration from environment variables (.env).
2. Maintains conversation context across multiple turns using ChatPromptTemplate with MessagesPlaceholder.
3. Uses Pydantic models (ChatMessage, MemoryChatRequest, MemoryChatResponse) for structured serialization.
4. Dynamically appends user questions and assistant answers to preserve context across turns.
"""

import os

from dotenv import find_dotenv, load_dotenv
from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder
from langchain_openai import ChatOpenAI
from pydantic import BaseModel

# ---------------------------------------------------------------------------
# Configuration & Environment Setup
# ---------------------------------------------------------------------------
# Load API keys and model names from .env
load_dotenv(find_dotenv())


# ---------------------------------------------------------------------------
# Request & Response Schemas (Pydantic)
# ---------------------------------------------------------------------------
class ChatMessage(BaseModel):
    """Single chat turn in conversation history."""

    role: str
    content: str


class MemoryChatRequest(BaseModel):
    """Input payload for memory chat queries."""

    message: str = "My favorite color is navy blue."
    history: list[ChatMessage] = []


class MemoryChatResponse(BaseModel):
    """Output payload containing assistant response and updated history."""

    message: str
    response: str
    history: list[ChatMessage]


# ---------------------------------------------------------------------------
# Model & Prompt Chain Setup
# ---------------------------------------------------------------------------
# ① Initialize the ChatOpenAI client
#   (placeholder key avoids an import-time crash when OPENAI_API_KEY is unset)
model = ChatOpenAI(
    model=os.getenv("OPENAI_MODEL", "gpt-4o-mini"),
    api_key=os.getenv("OPENAI_API_KEY") or "missing-key",
    base_url=os.getenv("OPENAI_BASE_URL") or None,
    timeout=15.0,
)

# ② Build prompt template injecting system instructions, chat history, and current question
#   MessagesPlaceholder("history") dynamically receives the list of past (role, content) tuples
prompt = ChatPromptTemplate.from_messages([
    ("system", "You are a friendly assistant. Use the conversation history to stay consistent."),
    MessagesPlaceholder("history"),
    ("human", "{question}"),
])

# ③ Assemble the LCEL pipeline (Prompt | Model)
chain = prompt | model


# ---------------------------------------------------------------------------
# Core Service Logic
# ---------------------------------------------------------------------------
def chat_with_memory(question: str, history: list[ChatMessage]) -> tuple[str, list[ChatMessage]]:
    """Execute a conversational chat turn with memory retention.

    Args:
        question: User message or query.
        history: Previous chat messages to provide context.

    Returns:
        Tuple of (assistant_response, updated_chat_history).
    """
    # ④ Convert the history sent by the browser into (role, content) tuples
    lc_history = [(msg.role, msg.content) for msg in history]

    # ⑤ Invoke the chain with accumulated history and the current user question
    answer = chain.invoke({"history": lc_history, "question": question}).content

    # ⑥ Append the current question and answer to preserve context for the next turn
    return answer, [
        *history,
        ChatMessage(role="user", content=question),
        ChatMessage(role="assistant", content=answer),
    ]

server/main.py

FastAPI route handler for POST /api/memory-chat (memory_chat_service) in server/main.py.

from dotenv import find_dotenv, load_dotenv
from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware

from services import (
    MemoryChatRequest,
    MemoryChatResponse,
    chat_with_memory,
)

# Load environment variables
load_dotenv(find_dotenv())

app = FastAPI(title="AI POCs API")

# Enable CORS for frontend requests
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.post("/api/memory-chat", response_model=MemoryChatResponse)
def memory_chat_service(req: MemoryChatRequest):
    # ① Validate user message and pass conversation history to memory chat service
    if not req.message.strip():
        raise HTTPException(status_code=400, detail="Message cannot be empty")
    try:
        reply, history = chat_with_memory(req.message, req.history)
        return MemoryChatResponse(message=req.message, response=reply, history=history)
    except Exception as exc:
        raise HTTPException(status_code=500, detail=str(exc))
