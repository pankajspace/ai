📦 Custom Inventory Tool wraps an internal data source — here a small mock stock table — in a custom Strands @tool, check_inventory(product_id).

How It Works#

The idea behind the demo, the request it sends and the function calls that answer it.

1

Concept#

Agents become useful when they can reach your own systems. The model knows nothing about PROD-123; the tool looks it up and returns a plain sentence the model can repeat.

In a real project the dictionary inside the tool would be a database query or an internal API call; the agent code would not change.

2

Theory & Concepts#

  • Custom tools: any function you can write can become a tool.
  • Args section in the docstring: describes each parameter (e.g. "The product ID to check (e.g., PROD-123)") so the model passes the right value.
  • Human-readable results: returning a sentence keeps the model's final answer accurate.
  • After the run, the service reads agent.messages and lists every toolUse block, so the card can show which tools the agent called and with what arguments.

Custom Inventory Tool Agent Service.

"""Custom Inventory Tool Agent Service.

Demonstrates building domain-specific custom tools:
1. Simulates an internal proprietary system or inventory database.
2. Custom tool `check_inventory(product_id: str)` with strict typing & docstrings.
3. Natural language query resolution against mock product inventory.
"""

import os

from dotenv import find_dotenv, load_dotenv
from pydantic import BaseModel
from strands import Agent, tool
from strands.models.bedrock import BedrockModel

# ① Load AWS credentials and Bedrock configuration from .env
load_dotenv(find_dotenv())


class CustomInventoryRequest(BaseModel):
    """Input payload for Custom Inventory Agent."""

    question: str = "Is PROD-123 in stock?"


class CustomInventoryResponse(BaseModel):
    """Output payload from Custom Inventory Agent."""

    question: str
    response: str
    tool_calls: list[str]


# ② Resolve the target Bedrock model identifier
model_id = os.getenv("BEDROCK_MODEL_ID", "amazon.nova-lite-v1:0")


@tool
def check_inventory(product_id: str) -> str:
    """Check if a product is in stock.

    Args:
        product_id: The product ID to check (e.g., "PROD-123")
    """
    # Define the mock product inventory catalog (replace with a real DB query in production)
    inventory = {
        "PROD-123": 15,
        "PROD-456": 0,
        "PROD-789": 8,
    }

    # Look up the available unit count for the requested SKU
    quantity = inventory.get(product_id, 0)

    # Return a human-readable stock status message
    if quantity > 0:
        return f"Product {product_id} is in stock. We have {quantity} units available."
    else:
        return f"Product {product_id} is currently out of stock."


def run_custom_inventory_agent(question: str = "Is PROD-123 in stock?") -> dict:
    """Run the Custom Inventory Agent."""
    # ③ Initialize the Strands Agent with BedrockModel and the custom check_inventory tool
    agent = Agent(model=BedrockModel(model_id=model_id), tools=[check_inventory])

    # ④ Run the agent on the inventory question
    response = agent(question)

    # ⑤ Collect every tool call the agent made from its message history
    tool_calls = [
        f"{block['toolUse']['name']}({block['toolUse']['input']})"
        for message in agent.messages
        for block in message["content"]
        if "toolUse" in block
    ]

    return {"question": question, "response": str(response), "tool_calls": tool_calls}

server/main.py

FastAPI route handler for POST /api/custom-inventory (custom_inventory_service) in server/main.py.

from dotenv import find_dotenv, load_dotenv
from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware

from services import (
    CustomInventoryRequest,
    CustomInventoryResponse,
    run_custom_inventory_agent,
)

# Load environment variables
load_dotenv(find_dotenv())

app = FastAPI(title="AI POCs API")

# Enable CORS for frontend requests
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.post("/api/custom-inventory", response_model=CustomInventoryResponse)
def custom_inventory_service(req: CustomInventoryRequest):
    # ① Validate question and query custom inventory tool agent
    if not req.question.strip():
        raise HTTPException(status_code=400, detail="Question cannot be empty")
    try:
        return CustomInventoryResponse(**run_custom_inventory_agent(req.question))
    except Exception as exc:
        raise HTTPException(status_code=500, detail=str(exc))
