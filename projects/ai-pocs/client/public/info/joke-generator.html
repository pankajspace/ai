Concept#

😂 Joke Generator uses OpenAI-compatible SDK routing pointed at Groq's LPU endpoint (https://api.groq.com/openai/v1) to generate a short joke with ultra-low latency.

Because Groq implements the OpenAI Chat Completions wire specification, switching providers requires only changing api_key, base_url, and the model identifier (llama-3.3-70b-versatile). The application logic remains identical to an OpenAI call.

2

Theory & Concepts#

Core Concepts:

  • OpenAI-Compatible API Standard: Modern inference providers (Groq, Together, vLLM, Ollama) expose the same /v1/chat/completions schema, avoiding vendor lock-in.
  • Provider Portability: Overriding base_url in the OpenAI(...) constructor decouples client code from the underlying model host.
  • LPU Inference: Groq's Language Processing Unit delivers high tokens-per-second throughput for open-weights models like Llama 3.3 70B.

Groq Chat Completion Service - Joke Generator.

"""Groq Chat Completion Service - Joke Generator.

This service demonstrates using an alternative high-speed LLM provider (Groq)
via the OpenAI-compatible client interface:
1. Groq hosts open-weights models (such as LLaMA 3.3 70B) with high inference speed.
2. The standard `openai.OpenAI` client is reused by setting `base_url` to Groq's endpoint
   and authenticating with `GROQ_API_KEY`.
3. Pydantic models (JokeRequest, JokeResponse) validate and serialize API payloads.
4. Includes defensive validation to ensure API keys are configured before calling.

Run directly:
    python projects/ai-pocs/server/services/02_chat_groq.py
"""

import os
from dotenv import find_dotenv, load_dotenv
from openai import OpenAI
from pydantic import BaseModel, Field

# ---------------------------------------------------------------------------
# Configuration & Environment Setup
# ---------------------------------------------------------------------------
# Automatically locate and load the nearest .env file (e.g. at the repo or project root)
load_dotenv(find_dotenv())


# ---------------------------------------------------------------------------
# Request & Response Schemas (Pydantic)
# ---------------------------------------------------------------------------
class JokeRequest(BaseModel):
    """Input payload specifying the joke topic."""

    topic: str = Field(
        default="programming",
        description="Topic for the joke",
    )


class JokeResponse(BaseModel):
    """Output payload containing the topic and generated joke."""

    topic: str
    joke: str


# ---------------------------------------------------------------------------
# Core Service Logic
# ---------------------------------------------------------------------------
def get_groq_joke(topic: str = "programming") -> str:
    """Tell a funny joke on a topic using Groq.

    Args:
        topic: Topic for the joke (defaults to "programming").

    Returns:
        A humorous joke generated by the Groq model.

    Raises:
        ValueError: If GROQ_API_KEY is not defined in the environment.
    """
    # ① Verify that the Groq API key is present in environment variables
    api_key = os.getenv("GROQ_API_KEY")
    if not api_key:
        raise ValueError("GROQ_API_KEY is not configured in .env")

    # ② Read endpoint and model configuration (falling back to sensible defaults)
    base_url = os.getenv("GROQ_BASE_URL", "https://api.groq.com/openai/v1")
    model = os.getenv("GROQ_MODEL", "llama-3.3-70b-versatile")

    # ③ Initialize the OpenAI SDK client configured for Groq's base URL
    client = OpenAI(
        api_key=api_key,
        base_url=base_url,
        timeout=15.0,
    )

    # ④ Call the chat completions endpoint with system persona and user topic
    response = client.chat.completions.create(
        model=model,
        messages=[
            {"role": "system", "content": "You are a funny joke teller."},
            {"role": "user", "content": f"Tell me a joke about {topic}."},
        ],
        timeout=15.0,
    )

    # ⑤ Extract and return the joke text
    return response.choices[0].message.content or ""


# ---------------------------------------------------------------------------
# Standalone CLI Verification
# ---------------------------------------------------------------------------
if __name__ == "__main__":
    print("--- Testing Groq Joke Generator Service ---")
    print(get_groq_joke("programming"))

FastAPI route handler for POST /api/joke (joke_generator) in server/main.py.

from dotenv import find_dotenv, load_dotenv
from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware

from services import (
    JokeRequest,
    JokeResponse,
    get_groq_joke,
)

# Load environment variables
load_dotenv(find_dotenv())

app = FastAPI(title="AI POCs API")

# Enable CORS for frontend requests
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.post("/api/joke", response_model=JokeResponse)
def joke_generator(req: JokeRequest):
    # ① Normalize topic and call Groq joke generator service
    topic_name = req.topic.strip() if req.topic else "programming"
    try:
        joke_text = get_groq_joke(topic_name)
        return JokeResponse(topic=topic_name, joke=joke_text)
    except Exception as exc:
        raise HTTPException(status_code=500, detail=str(exc))
