The idea behind the demo, the request it sends and the function calls that answer it.

Concept#

Prebuilt Calculator Agent introduces the strands_tools ecosystem — a library of battle-tested, off-the-shelf tools maintained alongside the AWS Strands SDK. By simply writing from strands_tools import calculator and passing tools=[calculator] to Agent(), the agent gains a full symbolic and numerical mathematics engine powered by SymPy without writing a single line of custom tool code.

Paired with a focused system_prompt="You are a helpful math assistant.", the agent recognizes mathematical expressions, delegates evaluation to the prebuilt calculator tool, and explains the exact result.

2

Theory & Concepts#

1. Why LLMs Struggle with Multi-Digit Math

Transformer language models tokenize numbers into subword chunks and predict the next token via matrix multiplications and softmax probabilities — they do not run an arithmetic logic unit (ALU). While an LLM can memorize 12 × 12 = 144, asking it for 429 or the derivative of sin(x2) · ex by pure token prediction frequently produces plausible-looking wrong digits.

2. Symbolic & Numerical Capabilities of strands_tools.calculator

Unlike a basic four-function eval() wrapper, the prebuilt calculator tool supports multiple modes via SymPy:

  • Evaluate: Exact arithmetic, powers, roots, and trigonometry.
  • Solve: Algebraic equations and systems of equations.
  • Calculus: Symbolic differentiation (derive) and integration (integrate).
  • Matrix Operations: Determinants, inverses, and eigenvalues.

3. Standing Instructions via system_prompt

Passing system_prompt="You are a helpful math assistant." when constructing the Agent attaches a persistent system instruction to every Bedrock Converse call in the loop, priming the model to reach for its mathematical toolset and format explanations clearly.

server/services/04-ai-aws-strands/07_prebuilt_tools.py

Pre-built Calculator Tool Agent Service.

"""Pre-built Calculator Tool Agent Service.

Demonstrates integrating pre-built community tools with system prompts:
1. Standing System Prompt: "You are a helpful math assistant."
2. Prebuilt `calculator` tool from the `strands_tools` package (no tool code to write).
3. Evaluates complex mathematical queries with precise computation.
"""

import os

from dotenv import find_dotenv, load_dotenv
from pydantic import BaseModel
from strands import Agent
from strands.models.bedrock import BedrockModel
from strands_tools import calculator

# ① Load AWS credentials and Bedrock configuration from .env
load_dotenv(find_dotenv())


class PrebuiltCalculatorRequest(BaseModel):
    """Input payload for Prebuilt Calculator Agent."""

    query: str = "What's 42 raised to the power of 9?"


class PrebuiltCalculatorResponse(BaseModel):
    """Output payload from Prebuilt Calculator Agent."""

    query: str
    response: str
    tool_calls: list[str]


# ② Resolve the target Bedrock model identifier
model_id = os.getenv("BEDROCK_MODEL_ID", "amazon.nova-lite-v1:0")


def run_prebuilt_calculator_agent(query: str = "What's 42 raised to the power of 9?") -> dict:
    """Run the Prebuilt Calculator Agent."""
    # ③ Initialize the Strands Agent with the prebuilt calculator tool and a standing system prompt
    agent = Agent(
        model=BedrockModel(model_id=model_id),
        tools=[calculator],
        system_prompt="You are a helpful math assistant.",
    )

    # ④ Execute the math query
    response = agent(query)

    # ⑤ Collect every tool call the agent made from its message history
    tool_calls = [
        f"{block['toolUse']['name']}({block['toolUse']['input']})"
        for message in agent.messages
        for block in message["content"]
        if "toolUse" in block
    ]

    return {"query": query, "response": str(response), "tool_calls": tool_calls}

server/main.py

FastAPI route handler for POST /api/prebuilt-calculator (prebuilt_calculator_service) in server/main.py.

from dotenv import find_dotenv, load_dotenv
from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware

from services import (
    PrebuiltCalculatorRequest,
    PrebuiltCalculatorResponse,
    run_prebuilt_calculator_agent,
)

# Load environment variables
load_dotenv(find_dotenv())

app = FastAPI(title="AI POCs API")

# Enable CORS for frontend requests
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.post("/api/prebuilt-calculator", response_model=PrebuiltCalculatorResponse)
def prebuilt_calculator_service(req: PrebuiltCalculatorRequest):
    # ① Validate query and invoke safe AST math calculator agent
    if not req.query.strip():
        raise HTTPException(status_code=400, detail="Query cannot be empty")
    try:
        return PrebuiltCalculatorResponse(**run_prebuilt_calculator_agent(req.query))
    except Exception as exc:
        raise HTTPException(status_code=500, detail=str(exc))
