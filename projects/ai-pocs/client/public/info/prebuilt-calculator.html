🧮 Math Assistant#

🧮 Math Assistant uses a prebuilt tool — calculator from the strands_tools package — plus a standing system prompt, so there is no tool code to write at all.

Unit 1

How It Works#

The idea behind the demo, the request it sends and the function calls that answer it.

1

Concept#

Strands ships a library of ready-made tools. Importing calculator and passing it in tools=[calculator] gives the agent exact maths (powers, roots, equations, derivatives) that a model would otherwise guess.

The system_prompt ("You are a helpful math assistant.") is sent with every call and sets the agent's role.

2

Theory & Concepts#

  • Prebuilt tools: reuse tested tools instead of writing your own.
  • System prompt: a standing instruction for the whole conversation.
  • Exact vs approximate: 429 is easy for a calculator and error-prone for a language model.
  • After the run, the service reads agent.messages and lists every toolUse block, so the card can show which tools the agent called and with what arguments.
3

Request flow#

🧑 Browser PrebuiltCalculatorCard.tsx sends POST /api/prebuilt-calculator with { query }.
→
FastAPI route (main.py) prebuilt_calculator_service(req) calls run_prebuilt_calculator_agent(query).
→
Agent (17_prebuilt_tools.py) Bedrock writes an expression and calls the prebuilt calculator.
→
🧑 Browser Shows the answer and the calculator call.

server/services/17_prebuilt_tools.py

Pre-built Calculator Tool Agent Service.

"""Pre-built Calculator Tool Agent Service.

Demonstrates integrating pre-built community tools with system prompts:
1. Standing System Prompt: "You are a helpful math assistant."
2. Prebuilt `calculator` tool from the `strands_tools` package (no tool code to write).
3. Evaluates complex mathematical queries with precise computation.

Run directly:
    python projects/ai-pocs/server/services/17_prebuilt_tools.py
"""

import os
from typing import List

from dotenv import find_dotenv, load_dotenv
from pydantic import BaseModel, Field
from strands import Agent
from strands.models.bedrock import BedrockModel
from strands_tools import calculator

# ① Load AWS credentials and Bedrock configuration from .env
load_dotenv(find_dotenv())


class PrebuiltCalculatorRequest(BaseModel):
    """Input payload for Prebuilt Calculator Agent."""

    query: str = Field(
        default="What's 42 raised to the power of 9?",
        description="Math problem or expression to solve",
    )


class PrebuiltCalculatorResponse(BaseModel):
    """Output payload from Prebuilt Calculator Agent."""

    query: str
    response: str
    tool_calls: List[str]
    provider: str


# ② Resolve the target Bedrock model identifier
model_id = os.getenv("BEDROCK_MODEL_ID", "amazon.nova-lite-v1:0")


def run_prebuilt_calculator_agent(query: str = "What's 42 raised to the power of 9?") -> dict:
    """Run the Prebuilt Calculator Agent."""
    # ③ Initialize the Strands Agent with the prebuilt calculator tool and a standing system prompt
    agent = Agent(
        model=BedrockModel(model_id=model_id),
        tools=[calculator],
        system_prompt="You are a helpful math assistant.",
    )

    # ④ Execute the math query
    response = agent(query)

    # ⑤ Collect every tool call the agent made from its message history
    tool_calls = [
        f"{block['toolUse']['name']}({block['toolUse']['input']})"
        for message in agent.messages
        for block in message["content"]
        if "toolUse" in block
    ]

    return {
        "query": query,
        "response": str(response),
        "tool_calls": tool_calls,
        "provider": f"Strands + Bedrock ({model_id})",
    }


if __name__ == "__main__":
    out = run_prebuilt_calculator_agent()
    print("Calls:", out["tool_calls"])
    print("Response:", out["response"])

server/main.py

FastAPI route handler for POST /api/prebuilt-calculator (prebuilt_calculator_service) in server/main.py.

from dotenv import find_dotenv, load_dotenv
from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware

from services import (
    PrebuiltCalculatorRequest,
    PrebuiltCalculatorResponse,
    run_prebuilt_calculator_agent,
)

# Load environment variables
load_dotenv(find_dotenv())

app = FastAPI(title="AI POCs API")

# Enable CORS for frontend requests
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.post("/api/prebuilt-calculator", response_model=PrebuiltCalculatorResponse)
def prebuilt_calculator_service(req: PrebuiltCalculatorRequest):
    # ① Normalize query and invoke safe AST math calculator agent
    q = req.query.strip() if req.query else "What's 42 raised to the power of 9?"
    try:
        res = run_prebuilt_calculator_agent(q)
        return PrebuiltCalculatorResponse(**res)
    except Exception as exc:
        raise HTTPException(status_code=500, detail=str(exc))
