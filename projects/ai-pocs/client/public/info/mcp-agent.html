🏏 FastMCP Cricket Agent#

🏏 FastMCP Cricket Agent connects a Groq LLM to the cricket MCP server: tools are discovered with tools/list, converted to the OpenAI function format, and run with tools/call whenever the model asks.

Unit 1

How It Works#

The idea behind the demo, the request it sends and the function calls that answer it.

1

Concept#

This is the MCP client from the previous demo with an LLM in the loop. The agent never hard-codes tool schemas — whatever the server lists is what the model can use, so adding a tool to the server needs no change in the agent.

The loop runs up to 5 turns: send messages + tools to Groq; if the reply has tool calls, run each on the MCP server and append the output; otherwise the reply is the final answer. Each tool call is recorded in a trace list (tool, args, result) that the evals demo also reuses. call_llm() retries when the model tries to call a tool that does not exist.

2

Theory & Concepts#

  • Bridge: to_openai_format() maps MCP inputSchema to OpenAI parameters.
  • Tool loop: assistant tool_calls message, then one tool message per call, linked by id.
  • Grounding: live scores come from the server, not from the model's memory.
3

Request flow#

🧑 Browser McpAgentCard.tsx sends POST /api/mcp-agent with { question }.
→
FastAPI route (main.py) mcp_agent_service(req) runs asyncio.run(run_mcp_agent(question)).
→
Agent (30_mcp_agent.py) Starts cricket_server.py, lists its tools and runs the Groq tool-calling loop.
→
MCP server (cricket_server.py) Answers each tools/call with demo match data.
→
🧑 Browser Shows the answer and every step in trace: tool name, arguments and the MCP tool result.

MCP-Enabled LLM Agent Service.

"""MCP-Enabled LLM Agent Service.

Connects an LLM to the FastMCP cricket server:
1. Starts `cricket_server.py` over stdio and discovers its tools with `tools/list`.
2. Converts the MCP tool descriptors into the OpenAI function-calling format.
3. Runs the tool-calling loop: the LLM asks for a tool, the client runs it with `tools/call`,
   and the tool output is fed back until the LLM gives a final answer.
"""

import json
import os
import re
import sys
from pathlib import Path

from dotenv import find_dotenv, load_dotenv
from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client
from openai import OpenAI
from pydantic import BaseModel

load_dotenv(find_dotenv())


class McpAgentRequest(BaseModel):
    """Input payload for MCP Agent."""

    question: str = "What is the score in India vs West Indies?"


class McpAgentResponse(BaseModel):
    """Output payload from MCP Agent."""

    answer: str
    trace: list[dict]


# ① Model settings (Groq's OpenAI-compatible endpoint) and the MCP server to spawn over stdio
MODEL = os.getenv("GROQ_MODEL", "openai/gpt-oss-20b")
GROQ_BASE_URL = os.getenv("GROQ_BASE_URL", "https://api.groq.com/openai/v1")
server_script = str(Path(__file__).with_name("cricket_server.py"))
server = StdioServerParameters(command=sys.executable, args=[server_script])


def to_openai_format(mcp_tools):
    """MCP tool list -> format expected by OpenAI-compatible API."""
    return [
        {
            "type": "function",
            "function": {
                "name": t.name,
                "description": t.description or "",
                "parameters": t.inputSchema,
            },
        }
        for t in mcp_tools
    ]


def call_llm(llm, kwargs, retries=2):
    """Call the model, retrying when it tries to call a tool we never gave it."""
    last = None
    for _ in range(retries + 1):
        try:
            return llm.chat.completions.create(**kwargs).choices[0].message, None
        except Exception as e:
            last = str(e)
            if "tool_use_failed" not in last:
                return None, f"API ERROR: {last}"
    m = re.search(r'"name":\s*"([^"]+)"', last or "")
    tool = m.group(1) if m else "a tool"
    return None, f"MODEL TRIED TO CALL A TOOL WE NEVER GAVE IT ({tool}). Try running again."


async def run_mcp_agent(question: str) -> dict:
    """Run the MCP agent loop for a single user question; returns the answer and a tool trace."""
    # ② Initialize the Groq OpenAI-compatible client
    llm = OpenAI(api_key=os.getenv("GROQ_API_KEY"), base_url=GROQ_BASE_URL)
    trace = []

    messages = [
        {
            "role": "system",
            "content": (
                "You are a cricket assistant. Use ONLY the functions provided to get live data. "
                "Do not use any browser or code tools. Be brief."
            ),
        },
        {"role": "user", "content": question},
    ]

    # ③ Connect to the FastMCP cricket server over stdio and discover its tools
    async with stdio_client(server) as (read, write):
        async with ClientSession(read, write) as session:
            await session.initialize()
            tools = to_openai_format((await session.list_tools()).tools)

            # ④ Run the multi-step tool-calling loop (up to 5 turns)
            for _ in range(5):
                reply, error = call_llm(llm, {"model": MODEL, "messages": messages, "tools": tools, "temperature": 0})
                if error:
                    return {"answer": f"({error})", "trace": trace}

                # No tool requested -> this is the final answer
                if not reply.tool_calls:
                    return {"answer": reply.content or "", "trace": trace}

                # ⑤ Run each requested tool on the MCP server and feed the output back to the LLM
                messages.append(
                    {
                        "role": "assistant",
                        "content": reply.content or "",
                        "tool_calls": [
                            {
                                "id": c.id,
                                "type": "function",
                                "function": {"name": c.function.name, "arguments": c.function.arguments},
                            }
                            for c in reply.tool_calls
                        ],
                    }
                )
                for call in reply.tool_calls:
                    args = json.loads(call.function.arguments)
                    result = await session.call_tool(call.function.name, args)
                    text = result.content[0].text if result.content else "(empty)"
                    trace.append({"tool": call.function.name, "args": args, "result": text})
                    messages.append({"role": "tool", "tool_call_id": call.id, "content": text})

    return {"answer": "(stopped: too many steps)", "trace": trace}

Cricket FastMCP Server (`cricket_server.py`).

"""Cricket FastMCP Server (`cricket_server.py`).

Provides Model Context Protocol (MCP) tool endpoints for live cricket matches and player statistics:
1. `get_live_score(teams)`: Fetches the live scorecard, target, and match situation.
2. `get_player_stats(player_name)`: Fetches series batting statistics and highest scores.
3. Communicates over standard input/output (`stdio`) transport so MCP clients can spawn it as a subprocess.

Note: The match and player data below is mock/demo data for classroom exercises (no external API key needed).

Run locally (from this folder):
    python cricket_server.py
"""

import sys
from pydantic import Field
from mcp.server.fastmcp import FastMCP

# ---------------------------------------------------------------------------
# FastMCP Server Initialization
# ---------------------------------------------------------------------------
mcp = FastMCP("Cricket-Score-Server")

# ---------------------------------------------------------------------------
# Mock Data Store (Simulated Third-Party Sports API Data)
# ---------------------------------------------------------------------------
LIVE_MATCHES = {
    "india vs west indies": {
        "series": "India vs West Indies ODI Series, Sep-Oct 2026 (DEMO DATA)",
        "match": "2nd ODI",
        "status": "LIVE",
        "india": "287/6 (50 overs)",
        "west_indies": "198/5 (38.2 overs)",
        "target": 288,
        "required": "90 runs from 70 balls",
        "series_score": "India lead 1-0",
    }
}

PLAYER_STATS = {
    "shubman gill": {"team": "India", "series_runs": 164, "innings": 3, "highest": 150},
    "shai hope": {"team": "West Indies", "series_runs": 131, "innings": 2, "highest": 78},
}


# ---------------------------------------------------------------------------
# FastMCP Tool Definitions
# ---------------------------------------------------------------------------
@mcp.tool(description="Get the LIVE score of a cricket match. Use this for any question about the current score, who is winning, or runs required.")
def get_live_score(teams: str = Field(description="The two teams, e.g. 'India vs West Indies'")) -> dict:
    """Get the LIVE score of a cricket match."""
    # ① Log diagnostic trace to stderr (stdout is reserved strictly for MCP JSON-RPC frames)
    print(f"[server] get_live_score called with teams={teams!r}", file=sys.stderr)  # logs go to stderr, NEVER stdout
    # ② Normalize team names and look up the live match scorecard
    key = teams.strip().lower().replace("windies", "west indies")
    if key not in LIVE_MATCHES:
        return {"error": f"No live match found for '{teams}'. Try 'India vs West Indies'."}
    return LIVE_MATCHES[key]


@mcp.tool(description="Get a player's batting stats for the current series. Use this for questions about a specific player's runs.")
def get_player_stats(player_name: str = Field(description="Full player name, e.g. 'Shubman Gill'")) -> dict:
    """Get a player's batting stats for the current series."""
    # ① Log diagnostic trace to stderr
    print(f"[server] get_player_stats called with player_name={player_name!r}", file=sys.stderr)
    # ② Normalize player name and return series batting statistics
    key = player_name.strip().lower()
    if key not in PLAYER_STATS:
        return {"error": f"No stats found for '{player_name}'."}
    return PLAYER_STATS[key]


# ---------------------------------------------------------------------------
# Entry Point (Stdio Transport)
# ---------------------------------------------------------------------------
if __name__ == "__main__":
    mcp.run(transport="stdio")

FastAPI route handler for POST /api/mcp-agent (mcp_agent_service) in server/main.py.

import asyncio

from dotenv import find_dotenv, load_dotenv
from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware

from services import (
    McpAgentRequest,
    McpAgentResponse,
    run_mcp_agent,
)

# Load environment variables
load_dotenv(find_dotenv())

app = FastAPI(title="AI POCs API")

# Enable CORS for frontend requests
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.post("/api/mcp-agent", response_model=McpAgentResponse)
def mcp_agent_service(req: McpAgentRequest):
    # ① Run LLM agent connected to FastMCP cricket tools
    if not req.question.strip():
        raise HTTPException(status_code=400, detail="Question cannot be empty")
    try:
        return McpAgentResponse(**asyncio.run(run_mcp_agent(req.question)))
    except Exception as exc:
        raise HTTPException(status_code=500, detail=str(exc))
