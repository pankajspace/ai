Unit 1

How It Works#

The idea behind the demo, the request it sends and the function calls that answer it.

1

Concept#

Compare this with the Single-Tool Agent: there is no hand-written JSON schema and no manual loop. LangChain reads the function's name, type hints and docstring to build the tool description, and create_agent runs the call → tool → answer loop for you.

The response also reports whether a tool ran, found by checking for a message of type tool in the agent's message list.

2

Theory & Concepts#

  • Functions as tools: type hints say what arguments to pass; the docstring says when to use the tool.
  • Provider switch: PROVIDER = "groq" picks GROQ_MODEL, GROQ_API_KEY and GROQ_BASE_URL from .env.
  • Agent messages: agent.invoke() returns every message (human, AI, tool); the last one is the final answer.
3

Request flow#

🧑 Browser LangchainOneToolCard.tsx sends POST /api/langchain-one-tool with { message }.
→
FastAPI route (main.py) langchain_one_tool_service(req) calls run_langchain_one_tool(message).
→
Agent (06_langchain_one_tool.py) agent.invoke() lets the Groq model call get_weather(city) when needed.
→
🧑 Browser Shows { response, tool_called }.

"""
Langchain Version V1 - Agents (single tool)

Teaching idea: give the agent ONE tool (get_weather), and show how LangChain's
`create_agent` automatically inspects tool signatures, triggers the tool
when needed (e.g. weather queries), and answers general queries directly.
"""

import os

from dotenv import find_dotenv, load_dotenv
from langchain.agents import create_agent
from langchain_openai import ChatOpenAI
from pydantic import BaseModel

# ---------------------------------------------------------------------------
# Configuration & Provider Selection
# ---------------------------------------------------------------------------
# Load API keys and model names from .env
load_dotenv(find_dotenv())

# Pick a provider: "groq" (free + fast), "gemini" (free tier) or "openai" (needs billing).
# Its settings are read from <PROVIDER>_MODEL / <PROVIDER>_API_KEY / <PROVIDER>_BASE_URL in .env
# (get keys at https://console.groq.com or https://aistudio.google.com)
PROVIDER = "groq"
prefix = PROVIDER.upper()


# ---------------------------------------------------------------------------
# Request & Response Schemas (Pydantic)
# ---------------------------------------------------------------------------
class LangchainOneToolRequest(BaseModel):
    """Input payload for single-tool LangChain agent queries."""

    message: str = "What is the weather like in New York?"


class LangchainOneToolResponse(BaseModel):
    """Output payload containing the final response and tool call indicator."""

    message: str
    response: str
    tool_called: bool


# ---------------------------------------------------------------------------
# Tools
# ---------------------------------------------------------------------------
# Type hints (city: str) tell the model WHAT arguments to pass;
# the docstring tells the model WHEN to invoke this tool.
def get_weather(city: str) -> str:
    """Get the current weather for a given city."""
    return f"The weather in {city} is too hot to handle, 28 degrees C."


# ---------------------------------------------------------------------------
# Build the agent
# ---------------------------------------------------------------------------
# ① Initialize the LLM client pointed at the configured provider
#   (placeholder key avoids an import-time crash when the key is unset)
llm = ChatOpenAI(
    model=os.getenv(f"{prefix}_MODEL"),
    api_key=os.getenv(f"{prefix}_API_KEY") or "missing-key",
    base_url=os.getenv(f"{prefix}_BASE_URL") or None,
    temperature=0,
    timeout=20.0,
)

# ② Create the LangChain tool-calling agent with get_weather and system instructions
agent = create_agent(
    model=llm,
    tools=[get_weather],
    system_prompt=(
        "You are a helpful assistant. Use the available tools when needed. "
        "Always state the final result clearly and completely in your answer."
    ),
)


# ---------------------------------------------------------------------------
# Core Service Logic
# ---------------------------------------------------------------------------
def run_langchain_one_tool(question: str = "What is the weather like in New York?") -> tuple[str, bool]:
    """Run a user question through the single-tool LangChain agent."""
    # ③ Invoke the LangChain agent with the user's question
    messages = agent.invoke({"messages": [{"role": "user", "content": question}]})["messages"]

    # ④ The agent called the tool if any message in the trace has type "tool"
    tool_called = any(m.type == "tool" for m in messages)

    # ⑤ The last message is the final assistant reply
    return messages[-1].content, tool_called

server/main.py

FastAPI route handler for POST /api/langchain-one-tool (langchain_one_tool_service) in server/main.py.

from dotenv import find_dotenv, load_dotenv
from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware

from services import (
    LangchainOneToolRequest,
    LangchainOneToolResponse,
    run_langchain_one_tool,
)

# Load environment variables
load_dotenv(find_dotenv())

app = FastAPI(title="AI POCs API")

# Enable CORS for frontend requests
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.post("/api/langchain-one-tool", response_model=LangchainOneToolResponse)
def langchain_one_tool_service(req: LangchainOneToolRequest):
    # ① Validate message and invoke LangChain single-tool agent
    if not req.message.strip():
        raise HTTPException(status_code=400, detail="Message cannot be empty")
    try:
        reply, tool_called = run_langchain_one_tool(req.message)
        return LangchainOneToolResponse(message=req.message, response=reply, tool_called=tool_called)
    except Exception as exc:
        raise HTTPException(status_code=500, detail=str(exc))
