⚡ Async Parallel Tools#

⚡ Async Parallel Tools makes the warehouse lookup an async Strands tool and runs the agent with invoke_async, so three 2-second lookups finish together instead of one after another.

How It Works#

The idea behind the demo, the request it sends and the function calls that answer it.

1

Concept#

Async Tools (Parallel Warehouse Check) tackles the #1 UX bottleneck in production agent systems: sequential I/O latency. If an agent needs to check stock across three regional warehouses (east, west, and central) and each network call takes 2 seconds, running them one after another blocks the user for 3 × 2 s = 6 s on tool I/O alone.

By declaring the tool as a Python coroutine — @tool async def check_warehouse_inventory(product_id: str, warehouse: str) using non-blocking await asyncio.sleep(2) — and invoking the Strands agent with await agent.invoke_async(query), all three warehouse lookups execute concurrently on Python's asyncio event loop, completing the entire tool fan-out in ~2 seconds instead of ~6 seconds.

2

Theory & Concepts#

1. Single-Turn Multi-Tool Fan-Out

When asked "Can we ship 100 units of PROD-123? Check all warehouses: east, west, and central", the Bedrock model recognizes that the three lookups do not depend on one another. Instead of emitting one tool call and waiting, it emits all three toolUse blocks in a single assistant turn:

  • check_warehouse_inventory(product_id="PROD-123", warehouse="east") → 45
  • check_warehouse_inventory(product_id="PROD-123", warehouse="west") → 30
  • check_warehouse_inventory(product_id="PROD-123", warehouse="central") → 60

2. Blocking time.sleep vs. Non-Blocking asyncio.sleep

A synchronous time.sleep(2) (or blocking requests.get) freezes the OS thread, forcing calls to run serially. Declaring async def and using await asyncio.sleep(2) (or an async HTTP/DB driver like httpx.AsyncClient / asyncpg) yields control back to the event loop while waiting for network I/O, so all three 2-second waits overlap in wall-clock time: Ttotal ≈ max(t1, t2, t3) = 2 s rather than t1 + t2 + t3 = 6 s.

3. End-to-End Async FastAPI Integration

Because FastAPI natively runs async def route handlers on its Uvicorn asyncio event loop, awaiting run_async_tools_agent() (which awaits agent.invoke_async(query)) keeps the entire request non-blocking from HTTP ingress to tool execution, and returns parallel_duration_seconds so you can verify the speedup empirically.

Async Parallel Tools Agent Service.

"""Async Parallel Tools Agent Service.

Demonstrates parallel asynchronous tool execution:
1. Problem: Sequential tool invocations cause linear latency accumulation (3 x 2s = 6s).
2. Solution: An `async` tool lets the agent run all lookups concurrently (~2s total).
3. Tool: `check_warehouse_inventory(product_id: str, warehouse: str)` across `east`, `west`, `central`.
4. Measures and returns the total duration (sequential would be ~6s).
"""

import asyncio
import os
import time

from dotenv import find_dotenv, load_dotenv
from pydantic import BaseModel
from strands import Agent, tool
from strands.models.bedrock import BedrockModel

# ① Load AWS credentials and Bedrock configuration from .env
load_dotenv(find_dotenv())


class AsyncToolsRequest(BaseModel):
    """Input payload for Async Tools Agent."""

    query: str = "Can we ship 100 units of PROD-123? Check all warehouses: east, west, and central."


class AsyncToolsResponse(BaseModel):
    """Output payload from Async Tools Agent."""

    query: str
    response: str
    parallel_duration_seconds: float
    tool_calls: list[str]


# ② Resolve the target Bedrock model identifier
model_id = os.getenv("BEDROCK_MODEL_ID", "amazon.nova-lite-v1:0")


@tool
async def check_warehouse_inventory(product_id: str, warehouse: str) -> dict:
    """Check inventory at a specific warehouse.

    Args:
        product_id: Product ID to check
        warehouse: Warehouse identifier (e.g., "east", "west", "central")
    """
    # Simulate a 2-second network I/O delay without blocking the asyncio event loop
    await asyncio.sleep(2)

    # Look up stock count for the requested warehouse and product SKU
    data = {
        "east":    {"PROD-123": 45, "PROD-456": 12},
        "west":    {"PROD-123": 30, "PROD-456": 0},
        "central": {"PROD-123": 60, "PROD-456": 25},
    }

    quantity = data.get(warehouse, {}).get(product_id, 0)
    return {"warehouse": warehouse, "product_id": product_id, "quantity": quantity}


async def run_async_tools_agent(
    query: str = "Can we ship 100 units of PROD-123? Check all warehouses: east, west, and central.",
) -> dict:
    """Run the Async Tools Agent."""
    # ③ Initialize the Strands Agent with the async warehouse inventory tool
    agent = Agent(
        model=BedrockModel(model_id=model_id),
        tools=[check_warehouse_inventory],
    )

    # ④ Record start time and invoke the agent asynchronously so tool calls run in parallel
    start = time.time()
    response = await agent.invoke_async(query)
    elapsed = time.time() - start

    # ⑤ Collect the tool calls
    tool_calls = [
        f"{block['toolUse']['name']}({block['toolUse']['input']})"
        for message in agent.messages
        for block in message["content"]
        if "toolUse" in block
    ]

    return {
        "query": query,
        "response": str(response),
        "parallel_duration_seconds": round(elapsed, 1),
        "tool_calls": tool_calls,
    }

server/main.py

FastAPI route handler for POST /api/async-tools (async_tools_service) in server/main.py.

import asyncio

from dotenv import find_dotenv, load_dotenv
from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware

from services import (
    AsyncToolsRequest,
    AsyncToolsResponse,
    run_async_tools_agent,
)

# Load environment variables
load_dotenv(find_dotenv())

app = FastAPI(title="AI POCs API")

# Enable CORS for frontend requests
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.post("/api/async-tools", response_model=AsyncToolsResponse)
def async_tools_service(req: AsyncToolsRequest):
    # ① Validate query and run async parallel warehouse tools agent
    if not req.query.strip():
        raise HTTPException(status_code=400, detail="Query cannot be empty")
    try:
        return AsyncToolsResponse(**asyncio.run(run_async_tools_agent(req.query)))
    except Exception as exc:
        raise HTTPException(status_code=500, detail=str(exc))
