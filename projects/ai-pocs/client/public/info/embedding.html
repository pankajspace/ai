Concept#

🔢 Sentence Embedding encodes two sentences into 384-dimensional dense vectors using a local SentenceTransformer("all-MiniLM-L6-v2") model and computes their cosine similarity.

Unlike keyword matching, dense embeddings map semantically similar phrases (such as "I love machine learning" and "AI and deep learning are my passion") to nearby points in high-dimensional vector space, even when they share almost no words.

2

Theory & Concepts#

Core Concepts:

  • Bi-Encoder Sentence Transformers: Maps variable-length text into fixed-length 384-D vectors locally on CPU/GPU without external API calls.
  • Cosine Similarity: Measures the cosine of the angle between two vectors ($\frac{A \cdot B}{\|A\| \|B\|}$), ranging from $-1$ (opposite) to $+1$ (identical meaning).
  • Lazy Singleton Caching: _get_model() loads the weights once into memory and reuses the model across requests.
3

Request flow#

🧑 Browser EmbeddingCard.tsx sends POST /api/embedding with text1 and text2.
→
FastAPI Route (server/main.py) embedding_service(req) validates both texts and calls compute_similarity(text1, text2).
→
Vector Encoding (09_embedding.py) _get_model() retrieves the cached all-MiniLM-L6-v2 model and encodes [text1, text2] into 384-D vectors.
→
Similarity Calculation cosine_similarity(v1, v2) computes the dot product divided by the product of Euclidean norms.
→
🧑 Browser Returns EmbeddingResponse containing vector dimensions, 5-float previews, and the cosine similarity score.

server/services/09_embedding.py

Sentence Embedding & Similarity Service.

"""Sentence Embedding & Similarity Service.

This service demonstrates how text embeddings work:
1. Encodes text into dense numeric vectors using SentenceTransformer ("all-MiniLM-L6-v2", 384 dims).
2. Computes cosine similarity between two sentences using dot product and vector norms.
3. Provides dimension count and vector preview values.

Run directly:
    python projects/ai-pocs/server/services/09_embedding.py
"""

from dotenv import find_dotenv, load_dotenv
from pydantic import BaseModel, Field
from numpy import dot
from numpy.linalg import norm
from sentence_transformers import SentenceTransformer

load_dotenv(find_dotenv())

# ---------------------------------------------------------------------------
# Request & Response Schemas (Pydantic)
# ---------------------------------------------------------------------------
class EmbeddingRequest(BaseModel):
    """Input payload for text embedding and similarity comparison."""

    text1: str = Field(
        default="A cat is sleeping on the couch",
        description="First text to encode",
    )
    text2: str = Field(
        default="A kitten is napping on the sofa",
        description="Second text to encode and compare",
    )


class EmbeddingResponse(BaseModel):
    """Output payload containing similarity score and vector previews."""

    text1: str
    text2: str
    similarity: float
    dimensions: int
    preview_text1: list[float]
    preview_text2: list[float]


# ---------------------------------------------------------------------------
# Core Service Logic
# ---------------------------------------------------------------------------
_embedding_model: SentenceTransformer | None = None


def compute_similarity(
    text1: str = "A cat is sleeping on the couch",
    text2: str = "A kitten is napping on the sofa",
) -> dict:
    """Compute embeddings for two texts and calculate their cosine similarity.

    Args:
        text1: First input text.
        text2: Second input text.

    Returns:
        Dictionary matching EmbeddingResponse fields.
    """
    global _embedding_model
    # ① Load (or reuse cached) compact 384-dimensional SentenceTransformer embedding model
    if _embedding_model is None:
        _embedding_model = SentenceTransformer("all-MiniLM-L6-v2")
    model = _embedding_model

    # ② Encode both texts into 384-dimensional dense vectors
    v1 = model.encode(text1)
    v2 = model.encode(text2)

    # ③ Compute cosine similarity using dot product divided by the product of vector norms
    norm_product = float(norm(v1) * norm(v2))
    similarity = float(dot(v1, v2) / norm_product) if norm_product > 0 else 0.0

    # ④ Return similarity score, vector dimensionality, and 5-value vector previews
    return {
        "text1": text1,
        "text2": text2,
        "similarity": round(similarity, 4),
        "dimensions": int(v1.shape[0]),
        "preview_text1": [round(float(x), 4) for x in v1[:5]],
        "preview_text2": [round(float(x), 4) for x in v2[:5]],
    }


# ---------------------------------------------------------------------------
# Standalone CLI Verification
# ---------------------------------------------------------------------------
if __name__ == "__main__":
    print("--- Sentence Embedding & Similarity Service ---")
    s1 = "A cat is sleeping on the couch"
    s2 = "A kitten is napping on the sofa"
    result = compute_similarity(s1, s2)
    print(f"Sentence 1: '{s1}'")
    print(f"Sentence 2: '{s2}'")
    print(f"Vector dimensions: {result['dimensions']}")
    print(f"Vector 1 preview: {result['preview_text1']}")
    print(f"Vector 2 preview: {result['preview_text2']}")
    print(f"Cosine similarity: {result['similarity']}")

server/main.py

FastAPI route handler for POST /api/embedding (embedding_service) in server/main.py.

import threading
from contextlib import asynccontextmanager
from dotenv import find_dotenv, load_dotenv
from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware

from services import (
    EmbeddingRequest,
    EmbeddingResponse,
    compute_similarity,
)

# Load environment variables
load_dotenv(find_dotenv())


@asynccontextmanager
async def lifespan(app: FastAPI):
    # Pre-warm SentenceTransformer in background
    def warmup_embedding():
        try:
            compute_similarity("warmup", "warmup")
        except Exception:
            pass

    threading.Thread(target=warmup_embedding, daemon=True).start()
    yield


app = FastAPI(title="AI POCs API", lifespan=lifespan)

# Enable CORS for frontend requests
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.post("/api/embedding", response_model=EmbeddingResponse)
def embedding_service(req: EmbeddingRequest):
    # ① Validate both sentences and compute cosine similarity via SentenceTransformer
    text1 = req.text1.strip() if req.text1 else ""
    text2 = req.text2.strip() if req.text2 else ""
    if not text1 or not text2:
        raise HTTPException(status_code=400, detail="Both texts are required")
    try:
        res = compute_similarity(text1, text2)
        return EmbeddingResponse(**res)
    except Exception as exc:
        raise HTTPException(status_code=500, detail=str(exc))
