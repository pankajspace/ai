📝 Text Summarizer#

📝 Text Summarizer builds a LangChain LCEL chain — prompt | model | parser — and runs it on the text you paste to get a short, friendly summary from OpenAI.

6 Topics • 4 Explainers • 2 Python Files in Full
Unit 1

How It Works#

The idea behind the demo, the request it sends and the function calls that answer it.

1

Concept#

LangChain Expression Language (LCEL) lets you snap small parts together with the | operator. Here the prompt template fills in the text, the chat model answers, and the output parser turns the reply message into a plain string.

The chain is built once when the module loads; every request just calls chain.invoke({"data": text}).

2

Theory & Concepts#

  • Prompt templates: ChatPromptTemplate.from_template() keeps the instruction fixed and fills {data} by name.
  • Chat model wrapper: ChatOpenAI is the LangChain wrapper around the OpenAI API (temperature 0.3 for steady summaries).
  • Output parsers: StrOutputParser() unwraps the AI message into text.
  • Pipes: prompt | model | parser means "then" — the output of each step is the input of the next.
3

Request flow#

🧑 Browser SummarizerCard.tsx sends POST /api/summarize with { text }.
→
FastAPI route (main.py) summarizer_service(req) checks the text and calls summarize(text).
→
LCEL chain (03_langchain_summarizer.py) prompt fills the template → model calls OpenAI → parser returns a string.
→
🧑 Browser Shows { text, summary }.

server/services/03_langchain_summarizer.py

LangChain Text Summarizer Service.

"""LangChain Text Summarizer Service.

This service demonstrates prompt chaining using LangChain LCEL (LangChain Expression Language):
1. Loads API credentials and model configuration from environment variables (.env).
2. Sets up a ChatPromptTemplate with a data placeholder.
3. Chains ChatPromptTemplate | ChatOpenAI | StrOutputParser using the LCEL pipe operator (|).
4. Uses Pydantic models (SummarizerRequest, SummarizerResponse) for structured serialization.
5. Invokes the chain with input text to produce a concise, friendly summary.

Run directly:
    python projects/ai-pocs/server/services/03_langchain_summarizer.py
"""

import os
from dotenv import find_dotenv, load_dotenv
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from pydantic import BaseModel, Field

# ---------------------------------------------------------------------------
# Configuration & Environment Setup
# ---------------------------------------------------------------------------
load_dotenv(find_dotenv())

DEFAULT_SAMPLE_TEXT = (
    "Information about LangChain and its usage in building AI applications. "
    "We will explore how it simplifies the integration of language models into "
    "various applications. It provides a structured way to create prompts, manage "
    "outputs, and chain together multiple language model calls. This allows "
    "developers to build complex AI-driven workflows efficiently."
)

model_name = os.getenv("OPENAI_MODEL") or "gpt-4o-mini"
base_url = os.getenv("OPENAI_BASE_URL")
api_key = os.getenv("OPENAI_API_KEY") or "missing-key"


# ---------------------------------------------------------------------------
# Request & Response Schemas (Pydantic)
# ---------------------------------------------------------------------------
class SummarizerRequest(BaseModel):
    """Input payload for text summarization queries."""

    text: str = Field(
        default=DEFAULT_SAMPLE_TEXT,
        description="Text content to summarize",
    )


class SummarizerResponse(BaseModel):
    """Output payload containing the original text and generated summary."""

    text: str
    summary: str



# ---------------------------------------------------------------------------
# LangChain LCEL Chain Definition
# ---------------------------------------------------------------------------
# ① a reusable prompt with a {data} blank
prompt = ChatPromptTemplate.from_template(
    "Give a short, friendly summary of this long text:\n\n{data}"
)

# ② the same model from Class 1, wrapped for LangChain
model = ChatOpenAI(
    model=model_name,
    api_key=api_key,
    base_url=base_url if base_url else None,
    temperature=0.3,
    timeout=20.0,
)

# ③ the package-opener: hands back plain text
parser = StrOutputParser()

# ④ snap them together  (| means "then")
chain = prompt | model | parser


# ---------------------------------------------------------------------------
# Core Service Logic
# ---------------------------------------------------------------------------
def summarize(long_text: str = DEFAULT_SAMPLE_TEXT) -> str:
    """Summarize long text into a concise, friendly summary using LangChain.

    Args:
        long_text: Text content to summarize.

    Returns:
        Concise summary string generated by the LLM.
    """
    # ⑤ run it; the dict fills the {data} blank by name
    return chain.invoke({"data": long_text})



# ---------------------------------------------------------------------------
# Standalone CLI Verification
# ---------------------------------------------------------------------------
if __name__ == "__main__":
    print("--- LangChain Text Summarizer Service ---")
    print(summarize(DEFAULT_SAMPLE_TEXT))

FastAPI route handler for POST /api/summarize (summarizer_service) in server/main.py.

from dotenv import find_dotenv, load_dotenv
from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware

from services import (
    SummarizerRequest,
    SummarizerResponse,
    summarize,
)

# Load environment variables
load_dotenv(find_dotenv())

app = FastAPI(title="AI POCs API")

# Enable CORS for frontend requests
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.post("/api/summarize", response_model=SummarizerResponse)
def summarizer_service(req: SummarizerRequest):
    # ① Ensure input text is non-empty before summarizing via LangChain LCEL
    text_content = req.text.strip() if req.text else ""
    if not text_content:
        raise HTTPException(status_code=400, detail="Text cannot be empty")
    try:
        summary_result = summarize(text_content)
        return SummarizerResponse(text=text_content, summary=summary_result)
    except Exception as exc:
        raise HTTPException(status_code=500, detail=str(exc))
