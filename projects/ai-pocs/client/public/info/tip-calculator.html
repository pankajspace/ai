💵 Tip & Split Agent#

💵 Tip & Split Agent lets a Strands agent read a bill question in plain English, pull out the bill, tip % and number of people, and call one tool, calculate_tip(bill_amount, tip_percentage, num_people).

Unit 1

How It Works#

The idea behind the demo, the request it sends and the function calls that answer it.

1

Concept#

The point is intent over keywords: "The bill is $85, 20% tip, split 4 ways" and "Bill is $120, we want to tip 18%, split between 3 people" both end up as the same structured tool call, whatever the wording.

The tool does the maths exactly (no model arithmetic), and the card shows the breakdown: the tool's arguments plus the dict it returned, read from the agent's toolUse and toolResult messages.

2

Theory & Concepts#

  • Parameter extraction: the model fills typed arguments (float, int) from free text.
  • Default arguments: num_people: int = 1 becomes an optional tool parameter.
  • Tools for exact work: let code do the arithmetic; let the model do the language.
  • Reading results: Strands stores a dict tool result as JSON text in the toolResult block.
3

Request flow#

🧑 Browser TipCalculatorCard.tsx sends POST /api/tip-calculator with { query }.
→
FastAPI route (main.py) tip_calculator_service(req) calls run_tip_calculator_agent(query).
→
Agent (14_tip_calculator.py) Bedrock extracts the numbers and calls calculate_tip; Strands runs it.
→
Read the trace The service collects the toolUse arguments and the JSON toolResult into calculation.
→
🧑 Browser Shows the answer and the bill / tip / total / per-person breakdown.

Tip Calculator Agent Service.

"""Tip Calculator Agent Service.

Demonstrates intent-driven tool invocation over keyword matching:
1. Agent understands natural language intent regardless of phrasing.
2. Extracts numeric parameters: bill amount, tip percentage, and number of people.
3. Invokes `calculate_tip(bill_amount, tip_percentage, num_people)`.
4. Returns computed totals and split amounts.

Run directly:
    python projects/ai-pocs/server/services/14_tip_calculator.py
"""

import json
import os
from typing import Any, Dict, List, Optional

from dotenv import find_dotenv, load_dotenv
from pydantic import BaseModel, Field
from strands import Agent, tool
from strands.models.bedrock import BedrockModel

# ① Load AWS credentials and Bedrock configuration from .env
load_dotenv(find_dotenv())


class TipCalculatorRequest(BaseModel):
    """Input payload for Tip Calculator Agent."""

    query: str = Field(
        default="The bill is $85. What's a 20% tip, and how much does each person pay if we're splitting it 4 ways?",
        description="Natural language bill and tip inquiry",
    )


class TipCalculatorResponse(BaseModel):
    """Output payload from Tip Calculator Agent."""

    query: str
    response: str
    calculation: Optional[Dict[str, Any]] = None
    tool_calls: List[str]
    provider: str


# ② Resolve the target Bedrock model identifier
model_id = os.getenv("BEDROCK_MODEL_ID", "amazon.nova-lite-v1:0")


@tool
def calculate_tip(bill_amount: float, tip_percentage: float, num_people: int = 1) -> dict:
    """Calculate tip and split the bill among people.

    Args:
        bill_amount: Total bill amount in dollars
        tip_percentage: Tip percentage (e.g., 15, 18, 20)
        num_people: Number of people splitting the bill (default: 1)
    """
    # Compute the tip amount, combined total, and per-person share
    tip = bill_amount * (tip_percentage / 100)
    total = bill_amount + tip
    per_person = total / num_people

    # Return a dictionary with rounded monetary values
    return {
        "bill": bill_amount,
        "tip": round(tip, 2),
        "total": round(total, 2),
        "per_person": round(per_person, 2),
    }


def run_tip_calculator_agent(
    query: str = "The bill is $85. What's a 20% tip, and how much does each person pay if we're splitting it 4 ways?",
) -> dict:
    """Run the Tip Calculator Agent."""
    # ③ Initialize the Strands Agent with BedrockModel and the calculate_tip tool
    agent = Agent(model=BedrockModel(model_id=model_id), tools=[calculate_tip])

    # ④ The agent extracts bill, tip % and group size from plain English and calls the tool
    response = agent(query)

    # ⑤ Collect every tool call (toolUse) and tool output (toolResult) from the message history
    blocks = [block for message in agent.messages for block in message["content"]]
    tool_uses = [b["toolUse"] for b in blocks if "toolUse" in b]
    tool_results = [b["toolResult"] for b in blocks if "toolResult" in b]

    # ⑥ Show the last calculation: the tool's arguments plus the dict it returned (stored as JSON text)
    calculation = None
    if tool_results and tool_results[-1]["status"] == "success":
        result = json.loads(tool_results[-1]["content"][0]["text"])
        calculation = {"num_people": 1, **tool_uses[-1]["input"], **result}

    return {
        "query": query,
        "response": str(response),
        "calculation": calculation,
        "tool_calls": [f"{t['name']}({t['input']})" for t in tool_uses],
        "provider": f"Strands + Bedrock ({model_id})",
    }


if __name__ == "__main__":
    res = run_tip_calculator_agent()
    print("Calls:", res["tool_calls"])
    print("Response:", res["response"])

server/main.py

FastAPI route handler for POST /api/tip-calculator (tip_calculator_service) in server/main.py.

from dotenv import find_dotenv, load_dotenv
from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware

from services import (
    TipCalculatorRequest,
    TipCalculatorResponse,
    run_tip_calculator_agent,
)

# Load environment variables
load_dotenv(find_dotenv())

app = FastAPI(title="AI POCs API")

# Enable CORS for frontend requests
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.post("/api/tip-calculator", response_model=TipCalculatorResponse)
def tip_calculator_service(req: TipCalculatorRequest):
    # ① Normalize query and run tip and bill-split agent
    q = req.query.strip() if req.query else "The bill is $85. What's a 20% tip, and how much does each person pay if we're splitting it 4 ways?"
    try:
        res = run_tip_calculator_agent(q)
        return TipCalculatorResponse(**res)
    except Exception as exc:
        raise HTTPException(status_code=500, detail=str(exc))
