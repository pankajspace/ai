Concept#

Structured Output Variance & Determinism shows how to turn a stochastic text generator into a deterministic software component whose output can be safely parsed by downstream code. Given a free-text product review, the service asks the LLM to extract three fields (sentiment, rating, and pros_and_cons) under three progressively stricter strategies at temperature=0.7:

  • Strategy A (Unconstrained Freeform): Asks for the three fields in plain English with no format constraint — producing conversational prose or bullet points that immediately crash a downstream json.loads() parser.
  • Strategy B (Prompt-Constrained JSON): Instructs the model in the prompt to "Respond in JSON format with keys..." — often works, but frequently wraps the JSON in ```json ... ``` markdown fences or adds conversational preamble.
  • Strategy C (API Schema-Enforced JSON Mode): Sets response_format={"type": "json_object"} in the API request so the inference engine constrains token sampling at the logit level, guaranteeing valid, parseable JSON.
2

Theory & Concepts#

1. A Semantically Correct Answer Can Still Crash Your Pipeline

To a human reader, "Sentiment: Positive (4/5). Pros: great camera, sleek design. Cons: weak battery." is a great summary. To a backend microservice that calls json.loads(raw_output) to insert rows into PostgreSQL, it is an unhandled JSONDecodeError: Expecting value: line 1 column 1. Software pipelines require syntactic determinism, not just semantic understanding.

2. Prompt Persuasion (Strategy B) vs. Constrained Decoding (Strategy C)

Asking for JSON in the prompt (Strategy B) merely nudges token probabilities; at temperature=0.7, the model may still emit markdown code fences (```json) or trailing commentary, requiring defensive regex stripping (re.sub(r"^```(?:json)?\s*|\s*```$", "", raw_b)). Passing response_format={"type": "json_object"} (or a strict JSON Schema) in Strategy C masks out invalid tokens during decoding so the model is mathematically prevented from emitting non-JSON syntax.

3. Why Temperature Is Kept at 0.7 Across All Three Strategies

Holding temperature=0.7 constant proves that Strategy C's reliability comes from structural API enforcement rather than greedy decoding. Even when the model has sampling freedom over word choice, its output structure remains 100% valid JSON.

4. Inspecting Parser Failures with check_json()

The helper check_json(strategy_name, raw_output, text_to_parse) runs json.loads() inside a try/except json.JSONDecodeError block and captures both parsed_data on success and the exact parser exception message (parse_error) on failure for side-by-side inspection.

Structured Output Variance & Determinism Benchmark Service.

"""Structured Output Variance & Determinism Benchmark Service.

Evaluates how output constraints transform stochastic models into deterministic pipeline components:
1. Strategy A (Unconstrained): Model asked for review summary freeform (high variance, brittle to parse).
2. Strategy B (Prompt-Constrained): Prompt instructs JSON format (occasionally wraps markdown code blocks or violates schema).
3. Strategy C (Schema-Enforced): Uses OpenAI Structured Outputs (`response_format: {"type": "json_object"}` or schema) guaranteeing valid parseable JSON.
"""

import json
import os
from typing import Any, Dict, List, Optional
from dotenv import find_dotenv, load_dotenv
from openai import OpenAI
from pydantic import BaseModel

load_dotenv(find_dotenv())


class VarianceDeterminismRequest(BaseModel):
    """Input payload for Variance & Determinism Benchmark."""

    review_text: str = "The new smartphone is amazing, the camera quality is top-notch but the battery life is a bit disappointing. I love the sleek design though! Rating: 4 out of 5 stars."


class StrategyOutput(BaseModel):
    strategy_name: str
    raw_output: str
    is_valid_json: bool
    parsed_data: Optional[Dict[str, Any]] = None
    parse_error: Optional[str] = None


class VarianceDeterminismResponse(BaseModel):
    """Output payload from Variance & Determinism Benchmark."""

    strategies: List[StrategyOutput]


def check_json(strategy_name: str, raw_output: str, text_to_parse: str) -> dict:
    """Try to parse a model output as JSON and record whether it worked."""
    try:
        return {"strategy_name": strategy_name, "raw_output": raw_output, "is_valid_json": True,
                "parsed_data": json.loads(text_to_parse), "parse_error": None}
    except json.JSONDecodeError as exc:
        return {"strategy_name": strategy_name, "raw_output": raw_output, "is_valid_json": False,
                "parsed_data": None, "parse_error": str(exc)}


def run_variance_determinism_benchmark(
    review_text: str = "The new smartphone is amazing, the camera quality is top-notch but the battery life is a bit disappointing. I love the sleek design though! Rating: 4 out of 5 stars.",
) -> dict:
    """Run extraction across the three determinism strategies."""
    # ① Initialize OpenAI client
    client = OpenAI(
        api_key=os.getenv("OPENAI_API_KEY"),
        base_url=os.getenv("OPENAI_BASE_URL", "https://api.openai.com/v1"),
    )
    model = os.getenv("OPENAI_MODEL", "gpt-4o-mini")

    # ② Strategy A: Unconstrained freeform prompt (high variance, usually fails JSON parsing)
    prompt_a = f"Extract product, sentiment, pros, cons, and rating from this review:\n\n{review_text}"
    resp_a = client.chat.completions.create(model=model, messages=[{"role": "user", "content": prompt_a}])
    text_a = resp_a.choices[0].message.content or ""

    # ③ Strategy B: Prompt-constrained JSON instructions (may still need markdown fence stripping)
    prompt_b = (
        f"Extract product, sentiment (positive/negative/mixed), pros (list), cons (list), and rating (number) "
        f"from this review as JSON with keys 'product', 'sentiment', 'pros', 'cons', 'rating'. "
        f"Do not include markdown ticks or commentary:\n\n{review_text}"
    )
    resp_b = client.chat.completions.create(model=model, messages=[{"role": "user", "content": prompt_b}])
    text_b = resp_b.choices[0].message.content or ""

    # ④ Strategy C: API Schema-Enforced JSON mode (response_format={"type": "json_object"})
    prompt_c = (
        f"Extract review metadata into JSON with keys 'product', 'sentiment', 'pros', 'cons', 'rating':\n\n{review_text}"
    )
    resp_c = client.chat.completions.create(
        model=model,
        messages=[{"role": "user", "content": prompt_c}],
        response_format={"type": "json_object"},
    )
    text_c = resp_c.choices[0].message.content or ""

    # ⑤ Check which outputs parse as JSON and return all three side by side
    return {
        "strategies": [
            check_json("Strategy A: Unconstrained (Freeform Prompt)", text_a, text_a),
            check_json(
                "Strategy B: Prompt-Constrained (Instructional JSON)",
                text_b,
                text_b.replace("```json", "").replace("```", "").strip(),
            ),
            check_json("Strategy C: Schema-Enforced (API Guaranteed JSON)", text_c, text_c),
        ],
    }

server/main.py

FastAPI route handler for POST /api/variance-determinism (variance_determinism_service) in server/main.py.

from dotenv import find_dotenv, load_dotenv
from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware

from services import (
    VarianceDeterminismRequest,
    VarianceDeterminismResponse,
    run_variance_determinism_benchmark,
)

# Load environment variables
load_dotenv(find_dotenv())

app = FastAPI(title="AI POCs API")

# Enable CORS for frontend requests
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.post("/api/variance-determinism", response_model=VarianceDeterminismResponse)
def variance_determinism_service(req: VarianceDeterminismRequest):
    # ① Run Structured Output determinism benchmark across 3 JSON strategies
    if not req.review_text.strip():
        raise HTTPException(status_code=400, detail="Review text cannot be empty")
    try:
        return VarianceDeterminismResponse(**run_variance_determinism_benchmark(req.review_text))
    except Exception as exc:
        raise HTTPException(status_code=500, detail=str(exc))
