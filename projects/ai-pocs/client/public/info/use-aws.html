Unit 1

How It Works#

The idea behind the demo, the request it sends and the function calls that answer it.

1

Concept#

"List all S3 buckets in my account" becomes use_aws(service_name="s3", operation_name="list_buckets", ...). The call runs against the real AWS account of the configured credentials and the agent summarises the result.

Because the tool can reach the whole AWS API, the credentials should only allow read-only actions. use_aws asks for confirmation before mutating calls, but that confirmation is skipped when BYPASS_TOOL_CONSENT=true (set by the Multi-Prebuilt Tools demo in the same server).

2

Theory & Concepts#

  • Natural language to API calls: the model fills service_name, operation_name, parameters and region.
  • Least privilege: the IAM policy is the real safety boundary for an agent with cloud access.
  • Operations list: the card shows each service.operation the agent called, read from the toolUse blocks.
3

Request flow#

🧑 Browser UseAwsCard.tsx sends POST /api/use-aws with { prompt }.
→
FastAPI route (main.py) use_aws_service(req) calls run_use_aws_agent(prompt).
→
Agent (19_use_aws.py) Bedrock chooses the AWS call; use_aws runs it with boto3.
→
AWS APIs S3 / STS / DynamoDB / ... return real account data.
→
🧑 Browser Shows the answer and the list of AWS operations.

server/services/19_use_aws.py

Natural Language Cloud / AWS Agent Service.

"""Natural Language Cloud / AWS Agent Service.

Demonstrates `use_aws` natural language cloud operations:
1. The prebuilt `use_aws` tool from `strands_tools` exposes the whole AWS API (via boto3) to the agent.
2. The agent translates a plain-English request into service_name + operation_name + parameters.
3. Calls run against the real AWS account of the configured credentials, so give them a read-only IAM policy.
   (BYPASS_TOOL_CONSENT=true, set by service 18, also skips use_aws's confirmation for mutating calls.)

Run directly:
    python projects/ai-pocs/server/services/19_use_aws.py
"""

import os
from typing import List

from dotenv import find_dotenv, load_dotenv
from pydantic import BaseModel, Field
from strands import Agent
from strands.models.bedrock import BedrockModel
from strands_tools import use_aws

# ① Load AWS credentials and Bedrock configuration from .env
load_dotenv(find_dotenv())


class UseAwsRequest(BaseModel):
    """Input payload for Use AWS Agent."""

    prompt: str = Field(
        default="List all S3 buckets in my account",
        description="Natural language AWS cloud operation request",
    )


class UseAwsResponse(BaseModel):
    """Output payload from Use AWS Agent."""

    prompt: str
    response: str
    operations_executed: List[str]
    provider: str


# ② Resolve the target Bedrock model identifier
model_id = os.getenv("BEDROCK_MODEL_ID", "amazon.nova-lite-v1:0")


def run_use_aws_agent(prompt: str = "List all S3 buckets in my account") -> dict:
    """Run the Use AWS Agent."""
    # ③ Initialize the Strands Agent with the prebuilt use_aws tool and cloud assistant system prompt
    agent = Agent(
        model=BedrockModel(model_id=model_id),
        tools=[use_aws],
        system_prompt="You are an AWS assistant that helps manage cloud resources.",
    )

    # ④ Execute the natural language AWS request
    response = agent(prompt)

    # ⑤ List the AWS API operations the agent chose (service.operation)
    operations = [
        f"{block['toolUse']['input']['service_name']}.{block['toolUse']['input']['operation_name']}"
        for message in agent.messages
        for block in message["content"]
        if "toolUse" in block
    ]

    return {
        "prompt": prompt,
        "response": str(response),
        "operations_executed": operations,
        "provider": f"Strands use_aws + Bedrock ({model_id})",
    }


if __name__ == "__main__":
    out = run_use_aws_agent()
    print("Operations:", out["operations_executed"])
    print("Response:", out["response"])

server/main.py

FastAPI route handler for POST /api/use-aws (use_aws_service) in server/main.py.

from dotenv import find_dotenv, load_dotenv
from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware

from services import (
    UseAwsRequest,
    UseAwsResponse,
    run_use_aws_agent,
)

# Load environment variables
load_dotenv(find_dotenv())

app = FastAPI(title="AI POCs API")

# Enable CORS for frontend requests
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.post("/api/use-aws", response_model=UseAwsResponse)
def use_aws_service(req: UseAwsRequest):
    # ① Normalize prompt and invoke AWS cloud assistant agent
    p = req.prompt.strip() if req.prompt else "List all S3 buckets in my account"
    try:
        res = run_use_aws_agent(p)
        return UseAwsResponse(**res)
    except Exception as exc:
        raise HTTPException(status_code=500, detail=str(exc))
