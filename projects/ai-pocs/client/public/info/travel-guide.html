✈️ Travel Guide#

✈️ Travel Guide sends one chat request to OpenAI (gpt-4o-mini) with a system persona and a user prompt, and returns the model's single travel suggestion for the city you type.

6 Topics • 4 Explainers • 2 Python Files in Full
Unit 1

How It Works#

The idea behind the demo, the request it sends and the function calls that answer it.

1

Concept#

This is the smallest possible LLM call: build a list of messages, send it to the Chat Completions API, and read back the reply text.

The system message sets the persona ("a witty travel guide") and the user message carries the actual task ("Suggest one thing to do in {city}"). Changing only the city changes the answer, while the tone stays the same.

2

Theory & Concepts#

  • Chat messages: an LLM conversation is a list of {role, content} items. system shapes behaviour, user asks, assistant is the model's reply.
  • Client + model: OpenAI() reads OPENAI_API_KEY from the environment; the model name comes from OPENAI_MODEL.
  • Reading the reply: the answer text lives at response.choices[0].message.content.
  • Timeouts: a 15-second timeout stops a slow API call from hanging the request.
3

Request flow#

🧑 Browser TravelGuideCard.tsx sends POST /api/travel with { city }.
→
FastAPI route (main.py) travel_suggestion(req) checks the city is not empty and calls get_travel_suggestion(city).
→
Service (01_chat_openai.py) Builds the system + user messages and calls client.chat.completions.create().
→
OpenAI API Returns one witty suggestion for the city.
→
🧑 Browser Shows { city, suggestion }.

OpenAI Chat Completion Service - Travel Guide.

"""OpenAI Chat Completion Service - Travel Guide.

This service demonstrates direct LLM chat completion using the official OpenAI API:
1. Loads API credentials and model configuration from environment variables (.env).
2. Uses Pydantic models (TravelRequest, TravelResponse) for type validation and HTTP serialization.
3. Formats system and user prompts to guide the LLM's persona and task.
4. Executes the OpenAI Chat Completion endpoint with a 15-second safety timeout.

Run directly:
    python projects/ai-pocs/server/services/01_chat_openai.py
"""

import os
from dotenv import find_dotenv, load_dotenv
from openai import OpenAI
from pydantic import BaseModel, Field

# ---------------------------------------------------------------------------
# Configuration & Environment Setup
# ---------------------------------------------------------------------------
# Automatically locate and load the nearest .env file (e.g. at the repo or project root)
load_dotenv(find_dotenv())


# ---------------------------------------------------------------------------
# Request & Response Schemas (Pydantic)
# ---------------------------------------------------------------------------
class TravelRequest(BaseModel):
    """Input payload for travel suggestion queries."""

    city: str = Field(
        default="Bangalore",
        description="City to get a travel suggestion for",
    )


class TravelResponse(BaseModel):
    """Output payload containing the target city and generated suggestion."""

    city: str
    suggestion: str


# ---------------------------------------------------------------------------
# Core Service Logic
# ---------------------------------------------------------------------------
def get_travel_suggestion(city: str = "Bangalore") -> str:
    """Suggest one thing to do in a given city using OpenAI.

    Args:
        city: Target city name (defaults to "Bangalore").

    Returns:
        A witty travel recommendation generated by the OpenAI model.
    """
    # ① Fetch model identifier configured in .env (defaults to gpt-4o-mini if unspecified)
    model = os.getenv("OPENAI_MODEL", "gpt-4o-mini")

    # ② Initialize the OpenAI client (reads OPENAI_API_KEY from environment)
    client = OpenAI()

    # ③ Call the Chat Completion endpoint
    # - system message: assigns the persona/tone ("witty travel guide")
    # - user message: provides the specific prompt instruction
    response = client.chat.completions.create(
        model=model,
        messages=[
            {"role": "system", "content": "You are a witty travel guide."},
            {"role": "user", "content": f"Suggest one thing to do in {city}."},
        ],
        timeout=15.0,
    )

    # ④ Extract and return the assistant's reply
    return response.choices[0].message.content or ""


# ---------------------------------------------------------------------------
# Standalone CLI Verification
# ---------------------------------------------------------------------------
if __name__ == "__main__":
    print("--- Testing OpenAI Travel Guide Service ---")
    print(get_travel_suggestion("Bangalore"))

FastAPI route handler for POST /api/travel (travel_suggestion) in server/main.py.

from dotenv import find_dotenv, load_dotenv
from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware

from services import (
    TravelRequest,
    TravelResponse,
    get_travel_suggestion,
)

# Load environment variables
load_dotenv(find_dotenv())

app = FastAPI(title="AI POCs API")

# Enable CORS for frontend requests
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.post("/api/travel", response_model=TravelResponse)
def travel_suggestion(req: TravelRequest):
    # ① Validate city input and delegate to OpenAI travel suggestion service
    city_name = req.city.strip() if req.city else "Bangalore"
    if not city_name:
        raise HTTPException(status_code=400, detail="City cannot be empty")
    try:
        # ② Invoke service and wrap in TravelResponse
        suggestion = get_travel_suggestion(city_name)
        return TravelResponse(city=city_name, suggestion=suggestion)
    except Exception as exc:
        raise HTTPException(status_code=500, detail=str(exc))
