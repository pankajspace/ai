Concept#

Travel Guide is the foundational building block of every LLM application: a stateless, single-turn call to the OpenAI Chat Completions API using gpt-4o-mini. Given any city name (such as "Bangalore" or "Kyoto"), the service constructs a two-message conversation and returns a concise, witty travel recommendation.

Even in this minimal example, the code separates who the model should be from what the user is asking:

  • System Message (Persona & Guardrails): Sets the behavioral frame ("You are a witty travel guide.") so the tone remains consistent regardless of which city the user types.
  • User Message (Task Input): Injects the dynamic variable (f"Suggest one thing to do in {city}.") into a clear, scoped instruction.
  • Production Client Hygiene: Uses environment-driven configuration (OPENAI_API_KEY and OPENAI_MODEL) and enforces a strict 15-second network timeout so a stalled upstream call never hangs the FastAPI worker.
2

Theory & Concepts#

1. The Chat Completions Message Protocol

Modern instruction-tuned LLMs do not just complete raw text strings; they consume an ordered array of role-tagged messages (messages=[...]). Each message has a role and content:

  • system — high-priority instructions that establish persona, tone, constraints, and output expectations before the user speaks.
  • user — the prompt, question, or task payload supplied by the human or calling application.
  • assistant — responses generated by the model (used in multi-turn conversations and tool loops).

2. Stateless Inference by Design

Every call to client.chat.completions.create() is completely independent. The OpenAI API retains no memory of previous requests. If you ask for "Bangalore" and then immediately ask "What about food there?", a stateless endpoint has no idea what "there" refers to unless earlier messages are re-sent (which the Memory Chat demo addresses).

3. Navigating the Response Envelope

The API returns a structured ChatCompletion object containing token usage metrics, model metadata, finish reasons, and a list of candidate choices. Because we request a single completion (n=1 by default), the generated text is extracted from response.choices[0].message.content, with or "" guarding against None when a response contains only tool calls or refusal metadata.

4. Externalized Configuration & Timeouts

Hardcoding API keys or model IDs inside application code makes key rotation and model upgrades risky. Loading OPENAI_API_KEY and OPENAI_MODEL via python-dotenv keeps secrets out of version control, while OpenAI(timeout=15.0) protects server threads from indefinite socket hangs.

OpenAI Chat Completion Service - Travel Guide.

"""OpenAI Chat Completion Service - Travel Guide.

This service demonstrates direct LLM chat completion using the official OpenAI API:
1. Loads API credentials and model configuration from environment variables (.env).
2. Uses Pydantic models (TravelRequest, TravelResponse) for type validation and HTTP serialization.
3. Formats system and user prompts to guide the LLM's persona and task.
4. Executes the OpenAI Chat Completion endpoint with a 15-second safety timeout.
"""

import os

from dotenv import find_dotenv, load_dotenv
from openai import OpenAI
from pydantic import BaseModel

# ---------------------------------------------------------------------------
# Configuration & Environment Setup
# ---------------------------------------------------------------------------
# Automatically locate and load the nearest .env file (e.g. at the repo or project root)
load_dotenv(find_dotenv())


# ---------------------------------------------------------------------------
# Request & Response Schemas (Pydantic)
# ---------------------------------------------------------------------------
class TravelRequest(BaseModel):
    """Input payload for travel suggestion queries."""

    city: str = "Bangalore"


class TravelResponse(BaseModel):
    """Output payload containing the target city and generated suggestion."""

    city: str
    suggestion: str


# ---------------------------------------------------------------------------
# Core Service Logic
# ---------------------------------------------------------------------------
def get_travel_suggestion(city: str = "Bangalore") -> str:
    """Suggest one thing to do in a given city using OpenAI.

    Args:
        city: Target city name (defaults to "Bangalore").

    Returns:
        A witty travel recommendation generated by the OpenAI model.
    """
    # ① Initialize the OpenAI client (reads OPENAI_API_KEY from environment)
    #   with a 15-second safety timeout
    client = OpenAI(timeout=15.0)

    # ② Fetch model identifier configured in .env (defaults to gpt-4o-mini if unspecified)
    model = os.getenv("OPENAI_MODEL", "gpt-4o-mini")

    # ③ Build the conversation messages:
    # - system message: assigns the persona/tone ("witty travel guide")
    # - user message: provides the specific prompt instruction
    messages = [
        {"role": "system", "content": "You are a witty travel guide."},
        {"role": "user", "content": f"Suggest one thing to do in {city}."},
    ]

    # ④ Call the Chat Completion endpoint
    response = client.chat.completions.create(model=model, messages=messages)

    # ⑤ Extract and return the assistant's reply
    return response.choices[0].message.content or ""

FastAPI route handler for POST /api/travel (travel_suggestion) in server/main.py.

from dotenv import find_dotenv, load_dotenv
from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware

from services import (
    TravelRequest,
    TravelResponse,
    get_travel_suggestion,
)

# Load environment variables
load_dotenv(find_dotenv())

app = FastAPI(title="AI POCs API")

# Enable CORS for frontend requests
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.post("/api/travel", response_model=TravelResponse)
def travel_suggestion(req: TravelRequest):
    # ① Validate city input and delegate to OpenAI travel suggestion service
    if not req.city.strip():
        raise HTTPException(status_code=400, detail="City cannot be empty")
    try:
        # ② Invoke service and wrap in TravelResponse
        return TravelResponse(city=req.city, suggestion=get_travel_suggestion(req.city))
    except Exception as exc:
        raise HTTPException(status_code=500, detail=str(exc))
