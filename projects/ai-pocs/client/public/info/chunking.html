Concept#

🧩 Document Chunking splits long text into smaller overlapping windows of configurable chunk_size and chunk_overlap—the first stage of any Retrieval-Augmented Generation (RAG) ingestion pipeline.

Embedding models have finite token limits and perform best when each vector represents a focused passage. By advancing the window by step = chunk_size - chunk_overlap, adjacent chunks share boundary context so sentences split across a boundary are not lost during retrieval.

2

Theory & Concepts#

Core Concepts:

  • Chunk Size Trade-off: Smaller chunks yield sharper embedding similarity; larger chunks preserve more surrounding context for the LLM.
  • Sliding Window Overlap: Overlapping characters (chunk_overlap) prevent semantic concepts at chunk edges from being severed.
  • Stride Formula: Each chunk starts at i = 0, step, 2*step, ... where step = chunk_size - chunk_overlap.
3

Request flow#

🧑 Browser ChunkingCard.tsx sends POST /api/chunk with text, chunk_size, and chunk_overlap.
→
FastAPI Route (server/main.py) chunking_service(req) validates that text is non-empty and calls chunk_text().
→
Sliding Window Slicer (08_chunking.py) chunk_text() validates chunk_overlap < chunk_size, computes step = chunk_size - chunk_overlap, and slices the string.
→
🧑 Browser Returns ChunkingResponse with total_chunks, parameters, and the list of chunk strings.

Text Chunking Service.

"""Text Chunking Service.

This service splits long documents into smaller, overlapping chunks suitable
for vector embeddings and retrieval (RAG).

Run directly:
    python projects/ai-pocs/server/services/08_chunking.py
"""

from pydantic import BaseModel, Field

from langchain_text_splitters import RecursiveCharacterTextSplitter

DEFAULT_SAMPLE_TEXT = (
    "Retrieval-Augmented Generation (RAG) combines search retrieval with generative AI models. "
    "Before documents can be searched efficiently, they must be broken down into smaller pieces. "
    "This process is called chunking. "
    "RecursiveCharacterTextSplitter splits documents on paragraph breaks, line breaks, and spaces "
    "to keep semantically related sentences together. "
    "Chunk overlap ensures that context across boundaries is not lost between adjacent chunks. "
    "These chunks are then converted into numerical vectors using embedding models, allowing "
    "similarity search to locate the most relevant sections when answering a user question."
)


# ---------------------------------------------------------------------------
# Request & Response Schemas (Pydantic)
# ---------------------------------------------------------------------------
class ChunkingRequest(BaseModel):
    """Input payload for text chunking."""

    text: str = Field(
        default=DEFAULT_SAMPLE_TEXT,
        description="Document text to split into chunks",
    )
    chunk_size: int = Field(
        default=250,
        ge=20,
        le=5000,
        description="Target maximum characters per chunk",
    )
    chunk_overlap: int = Field(
        default=40,
        ge=0,
        le=1000,
        description="Character overlap between adjacent chunks",
    )


class ChunkingResponse(BaseModel):
    """Output payload containing generated chunks and configuration."""

    total_chunks: int
    chunk_size: int
    chunk_overlap: int
    chunks: list[str]


# ---------------------------------------------------------------------------
# Core Service Logic
# ---------------------------------------------------------------------------
def chunk_text(
    text: str = DEFAULT_SAMPLE_TEXT,
    chunk_size: int = 250,
    chunk_overlap: int = 40,
) -> list[str]:
    """Split text into overlapping chunks using RecursiveCharacterTextSplitter.

    Args:
        text: Input text document.
        chunk_size: Target characters per chunk.
        chunk_overlap: Shared characters between adjacent chunks.

    Returns:
        List of text chunks.
    """
    # ① Configure RecursiveCharacterTextSplitter with target chunk size and overlap
    splitter = RecursiveCharacterTextSplitter(
        chunk_size=chunk_size,        # aim for target chars per chunk
        chunk_overlap=chunk_overlap,  # adjacent chunks share chars (context glue)
    )
    # ② Split the document text into overlapping chunks preserving natural boundaries
    return splitter.split_text(text)


# ---------------------------------------------------------------------------
# Standalone CLI Verification
# ---------------------------------------------------------------------------
if __name__ == "__main__":
    print("--- Text Chunking Service ---")
    chunks = chunk_text(DEFAULT_SAMPLE_TEXT, chunk_size=200, chunk_overlap=40)
    print(f"Total chunks: {len(chunks)}")
    for idx, c in enumerate(chunks, 1):
        print(f"\nChunk #{idx} ({len(c)} chars):\n{c}")

FastAPI route handler for POST /api/chunk (chunking_service) in server/main.py.

from dotenv import find_dotenv, load_dotenv
from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware

from services import (
    ChunkingRequest,
    ChunkingResponse,
    chunk_text,
)

# Load environment variables
load_dotenv(find_dotenv())

app = FastAPI(title="AI POCs API")

# Enable CORS for frontend requests
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.post("/api/chunk", response_model=ChunkingResponse)
def chunking_service(req: ChunkingRequest):
    # ① Validate text and split into overlapping chunks
    text_content = req.text.strip() if req.text else ""
    if not text_content:
        raise HTTPException(status_code=400, detail="Text cannot be empty")
    try:
        chunks = chunk_text(
            text=text_content,
            chunk_size=req.chunk_size,
            chunk_overlap=req.chunk_overlap,
        )
        return ChunkingResponse(
            total_chunks=len(chunks),
            chunk_size=req.chunk_size,
            chunk_overlap=req.chunk_overlap,
            chunks=chunks,
        )
    except Exception as exc:
        raise HTTPException(status_code=500, detail=str(exc))
