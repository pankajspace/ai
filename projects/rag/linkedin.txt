🚀 Day 3 — I built a RAG Lab that turns documents into searchable knowledge.

After raw LLM calls and LangChain agents, today was all about Retrieval-Augmented Generation — helping an LLM answer from actual context instead of relying only on what it already knows. ✨

What the RAG Lab does:
🧠 Embeddings — compares the meaning of two sentences using local sentence-transformer vectors
✂️ Chunking — splits long text into overlapping chunks so context doesn't get lost
🗂️ Vector Indexing — stores embedded chunks in Chroma for semantic search
🔍 RAG Q&A — asks GPT-4o mini to answer using retrieved facts from your own knowledge base
🔀 Reranking — improves retrieval quality with a cross-encoder
📄 PDF Text Chat — paste up to 1000 characters copied from a PDF, index it, and ask grounded questions

The big idea clicked for me today:
LLMs are powerful, but RAG makes them useful for your own data.

The pipeline is surprisingly logical:
📄 load the content
✂️ chunk it
🧠 embed it
🗂️ store it in a vector database
🔍 retrieve the most relevant chunks
🤖 generate an answer grounded in that context
