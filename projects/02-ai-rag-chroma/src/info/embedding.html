🔢 Sentence Embedding#

🔢 Sentence Embedding turns two sentences into 384-number vectors with the local all-MiniLM-L6-v2 model and measures how close their meanings are with cosine similarity. No API key is needed.

How It Works#

The idea behind the demo, the request it sends and the function calls that answer it.

1

Concept#

Sentence Embeddings demonstrates how AI systems measure semantic similarity (meaning) rather than keyword overlap. Using the local HuggingFace SentenceTransformer("all-MiniLM-L6-v2") model, the service encodes two input sentences into 384-dimensional dense floating-point vectors and computes their cosine similarity.

Because the embedding model maps concepts with similar meanings to nearby directions in 384-dimensional space, "A cat is sleeping on the couch" and "A kitten is napping on the sofa" produce a high similarity score (~0.75+) despite sharing almost no content words. The response returns the rounded similarity score, the vector dimensionality (384), and the first 5 coordinates of each vector so you can inspect the numerical representation.

2

Theory#

1. From Discrete Words to Dense Semantic Vectors

Traditional search engines (like BM25 or SQL LIKE) match exact tokens: searching for "sofa" misses documents that only say "couch". An embedding model is a neural network trained on millions of sentence pairs to project text into a continuous 384-dimensional geometric space (R384) where distance corresponds to semantic relatedness.

2. Cosine Similarity Mathematics

To compare two embedding vectors v1 and v2, the service computes the cosine of the angle between them using NumPy's dot and norm:

similarity(v1, v2) = dot(v1, v2) / (||v1|| × ||v2||)

  • Near 1.0: Vectors point in the same direction (synonyms or paraphrases).
  • Near 0.0: Vectors are orthogonal (unrelated topics).
  • Below 0.0: Vectors point in opposite directions.

3. Polysemy and Context Awareness

Unlike static word tables, transformer encoders read the whole sentence before producing the vector. The word "bank" in "deposit money at the bank" vs. "sit by the river bank" yields very different 384-number vectors because surrounding words shift the attention representations.

4. Startup Model Caching for Low-Latency Inference

Loading transformer weights from disk takes several hundred milliseconds. By instantiating model = SentenceTransformer("all-MiniLM-L6-v2") once at module import time, every subsequent HTTP request encodes sentences in a few milliseconds on CPU with zero external API cost.

Sentence Embedding & Similarity Service.

"""Sentence Embedding & Similarity Service.

This service demonstrates how text embeddings work:
1. Encodes text into dense numeric vectors using SentenceTransformer ("all-MiniLM-L6-v2", 384 dims).
2. Computes cosine similarity between two sentences using dot product and vector norms.
3. Provides dimension count and vector preview values.
"""

from numpy import dot
from numpy.linalg import norm
from pydantic import BaseModel
from sentence_transformers import SentenceTransformer


# ---------------------------------------------------------------------------
# Request & Response Schemas (Pydantic)
# ---------------------------------------------------------------------------
class EmbeddingRequest(BaseModel):
    """Input payload for text embedding and similarity comparison."""

    text1: str = "A cat is sleeping on the couch"
    text2: str = "A kitten is napping on the sofa"


class EmbeddingResponse(BaseModel):
    """Output payload containing similarity score and vector previews."""

    text1: str
    text2: str
    similarity: float
    dimensions: int
    preview_text1: list[float]
    preview_text2: list[float]


# ---------------------------------------------------------------------------
# Core Service Logic
# ---------------------------------------------------------------------------
# ① Load the compact 384-dimensional SentenceTransformer embedding model once at startup
model = SentenceTransformer("all-MiniLM-L6-v2")


def compute_similarity(text1: str, text2: str) -> dict:
    """Compute embeddings for two texts and calculate their cosine similarity.

    Args:
        text1: First input text.
        text2: Second input text.

    Returns:
        Dictionary matching EmbeddingResponse fields.
    """
    # ② Encode both texts into 384-dimensional dense vectors
    v1 = model.encode(text1)
    v2 = model.encode(text2)

    # ③ Compute cosine similarity using dot product divided by the product of vector norms
    #   similarity = dot(v1, v2) / (||v1|| * ||v2||)
    similarity = float(dot(v1, v2) / (norm(v1) * norm(v2)))

    # ④ Return similarity score, vector dimensionality, and 5-value vector previews
    return {
        "text1": text1,
        "text2": text2,
        "similarity": round(similarity, 4),
        "dimensions": len(v1),
        "preview_text1": [round(float(x), 4) for x in v1[:5]],
        "preview_text2": [round(float(x), 4) for x in v2[:5]],
    }

FastAPI route handler for POST /api/embedding (embedding_service) in server/main.py.

from dotenv import find_dotenv, load_dotenv
from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware

from services import (
    EmbeddingRequest,
    EmbeddingResponse,
    compute_similarity,
)

# Load environment variables
load_dotenv(find_dotenv())

app = FastAPI(title="AI RAG & Chroma API")

# Enable CORS for frontend requests
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.post("/api/embedding", response_model=EmbeddingResponse)
def embedding_service(req: EmbeddingRequest):
    # ① Validate both sentences and compute cosine similarity via SentenceTransformer
    if not req.text1.strip() or not req.text2.strip():
        raise HTTPException(status_code=400, detail="Both texts are required")
    try:
        return EmbeddingResponse(**compute_similarity(req.text1, req.text2))
    except Exception as exc:
        raise HTTPException(status_code=500, detail=str(exc))
