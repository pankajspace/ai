# AI Agents in Finance

Finance-first, code-first agents for research, analysis, risk and compliance

1. **[01. Sections 1–2: Finance-First Foundations](ai-agents-in-finance-sections-01-02.html)** — The finance knowledge an agent builder needs, plus hands-on code, explained step by step for beginners.
2. **[02. Sections 3–4: Frameworks & Fundamental Analysis](ai-agents-in-finance-sections-03-04.html)** — Agent frameworks by superpower, then a five-agent fundamental analysis system, an analyst in a box, explained line by line.
3. **[03. Section 5: Deep Search](ai-agents-in-finance-section-05.html)** — An analyst-grade deep search agent that plans, researches in parallel, validates with code and writes an investment memo.
4. **[04. Section 6: Reasoning Paradigms](ai-agents-in-finance-section-06.html)** — Seven ways an agent can think (self-refine, self-consistency, ReAct, CRITIC, reflexion, tree of thoughts and LATS) through one earnings week on an equity desk.
5. **[05. Sections 7–9: Teams of Agents](ai-agents-in-finance-sections-07-09.html)** — Designing multi-agent systems, an AI investment committee with backtesting and debate, and a compliance-first insurance claims pipeline.
6. **[06. Section 10: Agentic RAG in Finance](ai-agents-in-finance-section-10.html)** — Routing, query decomposition and self-correcting retrieval over filings and policies, hybrid search with reciprocal rank fusion, reranking and the RAG triad, with a LlamaIndex lab.
7. **[07. Sections 11–12: Evaluation & Production](ai-agents-in-finance-sections-11-12.html)** — Evaluate agents with a KYC scorecard, LLM judges, fairness and drift tests, then run them in production with reliability, cost control, tracing, safe releases and governance.
