Unit 1

How It Works#

The idea behind the demo, the request it sends and the function calls that answer it.

1

Concept#

Natural Language AWS Agent (use_aws) equips a Strands agent with the prebuilt use_aws tool from strands_tools, which acts as a universal bridge between natural-language requests and the AWS SDK for Python (boto3).

When you ask "List all S3 buckets in my account" or "Describe my EC2 instances in us-east-1", the agent translates your plain-English question into a structured use_aws invocation specifying service_name (e.g., "s3"), operation_name (e.g., "list_buckets"), parameters, region, and a human-readable label. The tool executes the real boto3 API call against the configured AWS account and returns the response for the agent to summarize.

2

Theory#

1. One Meta-Tool vs. Thousands of Individual API Tools

AWS has over 200 services and tens of thousands of API actions. Registering a separate @tool function for every AWS operation would blow past any LLM's context window. Instead, use_aws is a single parameterized meta-tool: the model relies on its pretraining knowledge of boto3 client names and snake_case operation names to fill in service_name, operation_name, and parameters dynamically.

2. IAM Least Privilege Is the True Security Boundary

Prompt instructions like "Please do not delete anything" are soft guardrails that can be bypassed by prompt injection or model mistakes. When giving an agent cloud access, the hard security boundary is the AWS IAM Policy attached to the credentials or instance role — always scope agent credentials to read-only permissions (ReadOnlyAccess or specific List* / Describe* actions).

3. Built-In Consent Refusal for Mutating & Sensitive Calls

As a second layer of defense, use_aws inspects the operation name before calling boto3. Mutating operations (such as create_*, delete_*, terminate_*, put_*) and sensitive secret reads (such as secretsmanager.get_secret_value) trigger an interactive confirmation prompt, which automatically fails closed when running inside a non-interactive web server process.

09_use_aws.py#

60 lines

Natural Language Cloud / AWS Agent Service.

"""Natural Language Cloud / AWS Agent Service.

Demonstrates `use_aws` natural language cloud operations:
1. The prebuilt `use_aws` tool from `strands_tools` exposes the whole AWS API (via boto3) to the agent.
2. The agent translates a plain-English request into service_name + operation_name + parameters.
3. Calls run against the real AWS account of the configured credentials, so give them a read-only IAM policy.
   Mutating calls and secret reads ask for confirmation, which is refused in the server (no terminal).
"""

import os

from dotenv import find_dotenv, load_dotenv
from pydantic import BaseModel
from strands import Agent
from strands.models.bedrock import BedrockModel
from strands_tools import use_aws

# ① Load AWS credentials and Bedrock configuration from .env
load_dotenv(find_dotenv())


class UseAwsRequest(BaseModel):
    """Input payload for Use AWS Agent."""

    prompt: str = "List all S3 buckets in my account"


class UseAwsResponse(BaseModel):
    """Output payload from Use AWS Agent."""

    prompt: str
    response: str
    operations_executed: list[str]


# ② Resolve the target Bedrock model identifier
model_id = os.getenv("BEDROCK_MODEL_ID", "amazon.nova-lite-v1:0")


def run_use_aws_agent(prompt: str = "List all S3 buckets in my account") -> dict:
    """Run the Use AWS Agent."""
    # ③ Initialize the Strands Agent with the prebuilt use_aws tool and cloud assistant system prompt
    agent = Agent(
        model=BedrockModel(model_id=model_id),
        tools=[use_aws],
        system_prompt="You are an AWS assistant that helps manage cloud resources.",
    )

    # ④ Execute the natural language AWS request
    response = agent(prompt)

    # ⑤ List the AWS API operations the agent chose (service, operation, parameters)
    tool_calls = [
        f"{block['toolUse']['name']}({block['toolUse']['input']})"
        for message in agent.messages
        for block in message["content"]
        if "toolUse" in block
    ]

    return {"prompt": prompt, "response": str(response), "operations_executed": tool_calls}

main.py#

34 lines

FastAPI route handler for POST /api/use-aws (use_aws_service) in server/main.py.

from dotenv import find_dotenv, load_dotenv
from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware

from services import (
    UseAwsRequest,
    UseAwsResponse,
    run_use_aws_agent,
)

# Load environment variables
load_dotenv(find_dotenv())

app = FastAPI(title="AWS Strands Agents API")

# Enable CORS for frontend requests
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.post("/api/use-aws", response_model=UseAwsResponse)
def use_aws_service(req: UseAwsRequest):
    # ① Validate prompt and invoke AWS cloud assistant agent
    if not req.prompt.strip():
        raise HTTPException(status_code=400, detail="Prompt cannot be empty")
    try:
        return UseAwsResponse(**run_use_aws_agent(req.prompt))
    except Exception as exc:
        raise HTTPException(status_code=500, detail=str(exc))
