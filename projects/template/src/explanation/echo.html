How It Works

1

Concept#

The Echo endpoint acts as the canonical pattern for every interactive feature tile in the platform:

  • Input Validation: The frontend checks that the user has entered non-empty text before enabling the submit button.
  • Environment Neutrality: All API calls use a relative path prefixed by data-api-base so the UI behaves identically whether mounted at http://localhost:8090/ or https://app.techtoday.click/template/.
  • Stateless Backend Processing: The Flask application reads the incoming JSON payload, passes it to the isolated business module (echo.py), and returns the serialized result.
2

Theory & Concepts#

Key architectural concepts demonstrated by this pattern:

  1. Reverse Proxy Path Forwarding: Production traffic passes through Nginx without stripping the prefix segment. Flask Blueprints registered with PATH_PREFIX map routes seamlessly across environments.
  2. Sliding-Window Rate Limiting: A SQLite-backed rate limiter on EC2 guards against abusive request bursts while permitting normal user exploration.
  3. Deterministic Error Handling: Bad input returns an HTTP 400 with a structured {"error": "..."} message; service failures return HTTP 500.
3

Request flow#

1. Client Browser User enters text → click Send
2. Nginx Reverse Proxy Applies rate limiting → proxy_pass to loopback port
3. Flask Blueprint Validates JSON body → calls echo()
4. Feature Module Processes payload → returns result

echo.py#

src/python/echo.py

Starter feature function echoing back user messages.

"""Starter feature: a dependency-free "echo" that transforms text.

This module exists so the template runs end to end without any API keys.
Replace it with your project's real feature modules (one module per feature,
each exposing a small function that ``app.py`` calls). Keeping features in
their own modules makes them easy to add, remove, or test in isolation.
"""


def echo(text: str) -> str:
    """Return a short, upper-cased confirmation of the input text.

    Args:
        text: The message to echo back.

    Returns:
        A formatted string echoing the input. Pure Python — no network or
        API keys — so it works offline and in CI.
    """
    # ① clean and format the message
    cleaned = text.strip()
    return f"You said: {cleaned.upper()} ({len(cleaned)} characters)"


if __name__ == "__main__":
    # Allow running this feature directly:  docker compose run --rm echo
    message = input("Enter a message to echo: ")
    print(echo(message))

app.py#

src/python/app.py

Flask Blueprint application with rate limiting and static routing.

import os
from pathlib import Path

from flask import Blueprint, Flask, jsonify, request
from flask_cors import CORS

from echo import echo
from rate_limiter import check_rate_limit

PATH_PREFIX = os.environ.get("PATH_PREFIX", "")
STATIC_DIR = Path(__file__).resolve().parents[1]
app = Flask(__name__, static_folder=str(STATIC_DIR))
CORS(app)

bp = Blueprint("main", __name__)


@bp.before_request
def enforce_rate_limit():
    if request.method == "POST":
        blocked, msg, retry_after = check_rate_limit(
            request, max_requests=30, window_seconds=3600
        )
        if blocked:
            resp = jsonify({"error": msg})
            resp.status_code = 429
            resp.headers["Retry-After"] = str(retry_after)
            return resp


@bp.route("/")
def index():
    with open(os.path.join(app.static_folder, "index.html"), encoding="utf-8") as f:
        html = f.read()
    html = html.replace('data-api-base=""', f'data-api-base="{PATH_PREFIX}"')
    return app.response_class(html, mimetype="text/html")


@bp.route("/css/")
def css(filename):
    return app.send_static_file(os.path.join("css", filename))


@bp.route("/js/")
def js(filename):
    return app.send_static_file(os.path.join("js", filename))


@bp.route("/explanation/")
@bp.route("/info/")
def explanation(filename):
    return app.send_static_file(os.path.join("explanation", filename))


@bp.route("/echo", methods=["POST"])
def echo_route():
    data = request.get_json(force=True, silent=True) or {}
    message = (data.get("message") or "").strip()
    if not message:
        return jsonify({"error": "Please provide a non-empty 'message'."}), 400
    try:
        result = echo(message)
        return jsonify({"result": result})
    except Exception as exc:
        return jsonify({"error": str(exc)}), 500


app.register_blueprint(bp, url_prefix=PATH_PREFIX)

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=5000, debug=True)
