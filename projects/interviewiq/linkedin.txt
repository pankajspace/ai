🚀 Day 6 — I built InterviewIQ: an AI mock-interview coach that uses tool-calling agents.

This one hit different. Instead of just passing prompts to an LLM and getting text back, the LLM dynamically decides which evaluation tools to call — like a real autonomous agent. ✨

What InterviewIQ does:
🎯 Mock Interview — answer real interview questions and get AI-powered evaluation
📊 Real-time Diagnostics — relevance score, STAR framework coverage, filler-word density
💬 Mid-Session Coach Chat — ask "What's my weakest area?" anytime and the agent calls its own report tool to answer
🏆 Final Assessment Report — aggregated session analysis with category breakdown and coaching recommendations
⚡ Load Sample Answers — "strong" and "weak" demo answers to see the tool-calling engine in action

The big idea that clicked for me today:
The LLM doesn't just call tools — it DECIDES which tools to call.

This is the ReAct pattern in practice:
🧠 LLM reads the tool schema (the "menu")
🔧 Chooses which tools to invoke based on the question
📋 Reads the tool results
🔄 Loops until it has enough data to give feedback
💡 Synthesises everything into coaching advice

That's what separates a real agent from a simple function wrapper — the LLM is the decision-maker, not just the text generator.

Built with:
🐍 Python + Flask
🤖 Groq (free tier) with OpenAI function-calling API
🔧 3 deterministic evaluation tools (regex-based, no LLM needed)
🧠 Session memory with anti-recency-bias weakest-area detection
🐳 Docker container with CI/CD auto-deploy
