🚀 Day 5 — I built AI Agents on AWS that don't just answer, they act.

The last four days were about calling LLMs, chaining them, grounding them with RAG, and shipping them in containers. Today was about the next leap: agents that use tools, plan their own steps, and complete real tasks — built with the AWS Strands Agents SDK on Amazon Bedrock. 🧵

I built an AWS Strands Lab that walks through the SDK, simplest to capstone:

🤖 Hello World Agent — no tools, so the agentic loop runs once. Bedrock answers directly.
🧮 Math Assistant — a pre-built calculator tool + system prompt for powers, equations, and derivatives.
💰 Tip Calculator — any phrasing of a tip question routes to the same tool. The agent reads intent, not keywords.
📦 Inventory Checker — a custom tool backed by a mock database, checking live stock.
📊 Sales Report Agent — three single-purpose tools (query, analyse, email); the agent plans the order itself.
🗄️ Inventory Manager — class-based tools sharing state, so updates persist across calls.
⚡ Warehouse Check — async tools run lookups in parallel: three ~2s checks finish in ~2s, not ~6s.
✈️ Travel Assistant (capstone) — checks weather, builds a packing list, prices the trip, and tells you if it fits your budget — deciding the tool sequence on its own.

The 3 big concepts that clicked today:
🛠️ Tools — an agent is only as capable as the actions you give it.
🔁 The agentic loop — the model calls a tool, reads the result, and decides the next step until the task is done.
🧠 Planning — you describe the goal, not the steps; the agent sequences the tools itself.

The real unlock: with Strands you define tools and a prompt, and Bedrock's model does the reasoning — no hand-written control flow deciding which tool runs when.
