💰 Tip Calculator

custom @tool via Strands + Bedrock

Concept

A tool-enabled agent where any phrasing of a tip-calculation question routes to the same calculate_tip tool without regex or intent classifiers. The @tool decorator exposes the Python function to Bedrock while Strands parses type hints and docstrings to build the tool's JSON schema automatically.

Theory & Concepts

The Tip Calculator demo illustrates function calling and semantic entity extraction in agent workflows:

  • Function Calling & Tool Offloading: LLMs often approximate arithmetic. Exposing calculate_tip enables the Bedrock agent to offload percentage and division calculations to deterministic Python code for 100% mathematical accuracy.
  • Semantic Intent Parsing: Whether the prompt is "What's 18% on $85?" or "Split an 85 dollar dinner 3 ways with 18% tip", the model extracts parameters and maps them to function arguments without handcrafted regex or classification rules.
  • Context-Aware Synthesis: After receiving the calculated dictionary (tip amount, grand total, and per-person breakdown), the agent seamlessly synthesizes a clean, friendly conversational summary for the user.

Backend

tip_agent.py 
"""Module 2 demo — a tool-enabled agent: the tip calculator.

The agent understands INTENT, not keywords: every phrasing of a tip question
routes to the same ``calculate_tip`` tool with no regex or intent classifier.
"""

# Import core Agent class and @tool decorator from Strands
from strands import Agent, tool
from strands.models.bedrock import BedrockModel

from config import MODEL_ID, agent_text


# @tool extracts parameter types (float, int) and defaults (num_people=1)
# to inform Bedrock how to parse unstructured text into structured arguments.
@tool
def calculate_tip(bill_amount: float, tip_percentage: float, num_people: int = 1) -> dict:
    """Calculate tip and split the bill among people.

    Args:
        bill_amount: Total bill amount in dollars
        tip_percentage: Tip percentage (e.g., 15, 18, 20)
        num_people: Number of people splitting the bill (default: 1)
    """
    # Step 1: Calculate tip amount and total payable
    tip = bill_amount * (tip_percentage / 100)
    total = bill_amount + tip

    # Step 2: Split the total bill among the party members
    per_person = total / num_people

    # Step 3: Return structured numerical breakdown to the agent
    return {
        "bill": bill_amount,
        "tip": round(tip, 2),
        "total": round(total, 2),
        "per_person": round(per_person, 2),
    }


def calculate(question: str) -> str:
    """Answer a natural-language tip question using the calculate_tip tool."""
    # Step 1: Create the agent and provide the calculate_tip tool
    agent = Agent(
        model=BedrockModel(model_id=MODEL_ID),
        tools=[calculate_tip],
        callback_handler=None,
    )

    # Step 2: The model maps user intent into bill_amount, tip_percentage, and party size,
    # invokes calculate_tip(), and explains the breakdown back to the user.
    return agent_text(agent(question))
