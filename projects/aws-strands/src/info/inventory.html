📦 Inventory Checker

custom tool with mock DB via Strands + Bedrock

Concept

When community tools do not fit private APIs or proprietary databases, you write custom tools. The @tool decorator, Python type hints, and docstrings are all the Strands framework needs to generate tool schemas. A local dictionary stands in for a production database, showing that agent interfaces remain identical regardless of the underlying data source.

Theory & Concepts

The Inventory Checker demo demonstrates how to ground AI in private, real-time data through custom tool integration:

  • Custom Tool Integration: Large Language Models cannot natively access internal databases. When asked "Do you have PROD-123 in stock?", the Bedrock agent avoids guessing by routing the question to the registered check_inventory tool.
  • Automatic Schema Generation: In inventory_agent.py, decorating a function with @tool and adding type hints (like product_id: str) allows Strands to automatically construct a JSON schema contract that the model inspects to decide when and how to call the function.
  • Decoupled Architecture: The demo's mock dictionary can be swapped for a live SQL query or REST API without altering agent prompt or orchestration code, demonstrating clean separation of concerns.

Backend

inventory_agent.py 
"""Module 2 demo — a custom tool: an online-store inventory check.

When community tools don't fit (internal API, proprietary database) you write
your own. The mock dictionary stands in for a real database; the agent-facing
part — decorator, type hints, docstring — is identical either way.
"""

# Import the core Agent class and @tool decorator from Strands
from strands import Agent, tool
from strands.models.bedrock import BedrockModel

from config import MODEL_ID, agent_text


# Decorating with @tool registers the function so Strands automatically extracts
# the schema (name, docstring, typed arguments) and provides it to Bedrock.
@tool
def check_inventory(product_id: str) -> str:
    """Check if a product is in stock.

    Args:
        product_id: The product ID to check (e.g., "PROD-123")
    """
    # Step 1: Query the data store (mock dictionary representing inventory database)
    inventory = {"PROD-123": 15, "PROD-456": 0, "PROD-789": 8}
    quantity = inventory.get(product_id, 0)

    # Step 2: Return a clear status string for the agent to incorporate into its answer
    if quantity > 0:
        return f"Product {product_id} is in stock. We have {quantity} units available."
    return f"Product {product_id} is currently out of stock."


def check(question: str) -> str:
    """Answer a stock question using the check_inventory custom tool."""
    # Step 1: Instantiate the agent with the custom tool registered
    agent = Agent(
        model=BedrockModel(model_id=MODEL_ID),
        tools=[check_inventory],  # Agent decides when and with what arguments to call this tool
        callback_handler=None,
    )

    # Step 2: Execute ReAct loop: the model decides to call check_inventory, observes the result,
    # and synthesizes a final conversational response.
    return agent_text(agent(question))
