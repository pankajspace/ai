⚡ Warehouse Check

async parallel tools via Strands + Bedrock

Concept

Three warehouse lookups at ~2 seconds each would take ~6 seconds when executed sequentially. By defining the tool as an asynchronous function (async def) and calling agent.invoke_async(), the tool calls run in parallel, finishing in ~2 seconds instead of ~6.

Theory & Concepts

The Warehouse Check demo highlights asynchronous tool concurrency for reducing latency bottlenecks in agentic workflows:

  • Parallel Tool Invocation: When Amazon Nova Pro recognizes it needs stock data from east, west, and central locations, it emits three independent tool calls simultaneously rather than waiting for each to finish.
  • Asynchronous Python Concurrency: By declaring check_warehouse_inventory with async def and driving the loop with agent.invoke_async(), Strands dispatches all queries concurrently on Python's event loop.
  • Latency Optimization: Because all network queries overlap, the total round trip is bounded by the slowest single query (~2s) rather than the sum of all queries (~6s), making agent responses responsive.

Backend

warehouse_agent.py 
"""Module 2 demo — async tools (parallel execution).

Three warehouse lookups at ~2 seconds each would take ~6 seconds one by one.
By making the tool ``async`` and using ``agent.invoke_async()``, the calls run
in PARALLEL, so the whole thing takes about 2 seconds instead.
"""

import asyncio

# Import asynchronous Agent runner and @tool decorator
from strands import Agent, tool
from strands.models.bedrock import BedrockModel

from config import MODEL_ID, agent_text


# An `async def` tool allows non-blocking concurrency: when the LLM requests
# inventory checks across multiple warehouses simultaneously, Strands executes
# all coroutines concurrently using asyncio.gather under the hood.
@tool
async def check_warehouse_inventory(product_id: str, warehouse: str) -> dict:
    """Check inventory at a specific warehouse.

    Args:
        product_id: Product ID to check
        warehouse: Warehouse identifier (e.g., "east", "west", "central")
    """
    # Step 1: Simulate network latency (2 seconds) to demonstrate asynchronous speedup
    await asyncio.sleep(2)

    # Step 2: Lookup the regional inventory dictionary
    data = {
        "east":    {"PROD-123": 45, "PROD-456": 12},
        "west":    {"PROD-123": 30, "PROD-456": 0},
        "central": {"PROD-123": 60, "PROD-456": 25},
    }
    quantity = data.get(warehouse, {}).get(product_id, 0)

    # Step 3: Return warehouse stock count dictionary
    return {"warehouse": warehouse, "product_id": product_id, "quantity": quantity}


def lookup(question: str) -> str:
    """Answer a multi-warehouse question, running the lookups in parallel."""

    async def run():
        # Step 1: Initialize the agent with the asynchronous tool
        agent = Agent(
            model=BedrockModel(model_id=MODEL_ID),
            tools=[check_warehouse_inventory],
            callback_handler=None,
        )
        # Step 2: invoke_async dispatches multiple tool calls in parallel rather than sequentially
        return await agent.invoke_async(question)

    # Step 3: Run the async event loop to completion and extract text reply
    return agent_text(asyncio.run(run()))
